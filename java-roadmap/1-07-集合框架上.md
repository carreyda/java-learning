## 1. 为什么需要集合

数组的局限性：

```java
// 数组：长度固定，类型单一，功能有限
int[] scores = new int[5];
scores[5] = 90;  // ❌ 越界异常，无法动态扩容

// 想删除中间某个元素？要手动移位，很麻烦
// 想判断是否包含某个值？要自己写循环
// 想存键值对？数组做不到
```

集合解决了这些问题：**动态扩容、丰富的操作方法、多种数据结构可选。**

```java
// 集合：动态、灵活
List<String> names = new ArrayList<>();
names.add("张三");
names.add("李四");
names.add("王五");
names.remove("李四");
System.out.println(names.contains("张三"));  // true
System.out.println(names.size());             // 2
```

## 2. 集合框架总览

Java 集合框架的核心接口：

```
Collection（单列集合）
  ├── List（有序、可重复）
  │     ├── ArrayList    ← 最常用，底层数组
  │     ├── LinkedList   ← 底层链表，插删快
  │     └── Vector       ← 线程安全，已过时
  │
  └── Set（无序、不重复）
        ├── HashSet      ← 最常用，底层哈希表
        ├── LinkedHashSet← 保持插入顺序
        └── TreeSet      ← 自动排序

Map（双列集合，键值对）
  ├── HashMap            ← 最常用，底层哈希表
  ├── LinkedHashMap      ← 保持插入顺序
  ├── TreeMap            ← 按键排序
  └── Hashtable          ← 线程安全，已过时
```

**选哪个的简单原则：**

- 需要按顺序存、可以重复 → `ArrayList`
- 需要去重 → `HashSet`
- 需要键值对查找 → `HashMap`
- 其他情况根据具体需求选择

## 3. List：有序可重复

### 3.1 ArrayList 基本操作

```java
import java.util.ArrayList;
import java.util.List;

// 声明：用接口类型接收（面向接口编程）
List<String> list = new ArrayList<>();

// 添加元素
list.add("苹果");
list.add("香蕉");
list.add("橙子");
list.add("苹果");       // 可以重复添加
list.add(1, "葡萄");    // 在下标 1 处插入

System.out.println(list);  // [苹果, 葡萄, 香蕉, 橙子, 苹果]
System.out.println(list.size());  // 5
```

### 3.2 访问与修改

```java
List<String> list = new ArrayList<>();
list.add("A");
list.add("B");
list.add("C");

// 访问
String s = list.get(0);          // "A"
int index = list.indexOf("B");    // 1
int last = list.lastIndexOf("A"); // 0

// 修改
list.set(1, "X");
System.out.println(list);  // [A, X, C]

// 判断
list.contains("A");        // true
list.isEmpty();            // false
```

### 3.3 删除元素

```java
List<String> list = new ArrayList<>();
list.add("A");
list.add("B");
list.add("C");
list.add("B");

// 按下标删除
list.remove(0);            // 删除下标 0 的元素，list = [B, C, B]

// 按值删除（只删第一个匹配的）
list.remove("B");          // list = [C, B]

// 清空
list.clear();
System.out.println(list.isEmpty());  // true
```

> ⚠️ **删除整数时的陷阱：**
>
> ```java
> List<Integer> nums = new ArrayList<>();
> nums.add(1);
> nums.add(2);
> nums.add(3);
>
> nums.remove(1);          // 调用的是 remove(int index)，删除下标1的元素
> nums.remove(Integer.valueOf(1));  // 才是删除值为1的元素
> ```

### 3.4 遍历 List

```java
List<String> list = List.of("苹果", "香蕉", "橙子");  // 不可变列表

// 方式一：普通 for（需要下标时用）
for (int i = 0; i < list.size(); i++) {
    System.out.println(i + ": " + list.get(i));
}

// 方式二：增强 for（最常用）
for (String fruit : list) {
    System.out.println(fruit);
}

// 方式三：forEach + Lambda（JDK 8+，简洁）
list.forEach(fruit -> System.out.println(fruit));
// 或方法引用
list.forEach(System.out::println);

// 方式四：迭代器（了解即可，遍历时删除元素必须用这个）
Iterator<String> it = list.iterator();
while (it.hasNext()) {
    String s = it.next();
    System.out.println(s);
}
```

### 3.5 子列表与转换

```java
List<Integer> nums = new ArrayList<>(List.of(1, 2, 3, 4, 5));

// 子列表（左闭右开）
List<Integer> sub = nums.subList(1, 4);  // [2, 3, 4]

// List 转数组
Object[] arr = nums.toArray();
Integer[] arr2 = nums.toArray(new Integer[0]);

// 数组转 List（注意：结果是固定大小的，不能 add/remove）
String[] array = {"A", "B", "C"};
List<String> fromArray = Arrays.asList(array);

// 可变的 List（可以 add/remove）
List<String> mutableList = new ArrayList<>(Arrays.asList(array));
```

### 3.6 LinkedList

底层是双向链表，在头尾插入/删除比 ArrayList 快，但随机访问慢：

```java
import java.util.LinkedList;

LinkedList<String> linked = new LinkedList<>();
linked.add("B");

// LinkedList 额外提供的头尾操作方法
linked.addFirst("A");   // 头部插入
linked.addLast("C");    // 尾部插入
linked.getFirst();      // 获取头部
linked.getLast();       // 获取尾部
linked.removeFirst();   // 删除头部
linked.removeLast();    // 删除尾部

// 可以当栈（Stack）用
linked.push("X");  // 等同于 addFirst
linked.pop();      // 等同于 removeFirst

// 可以当队列（Queue）用
linked.offer("Y"); // 尾部入队
linked.poll();     // 头部出队
```

## 4. Set：无序不重复

### 4.1 HashSet

```java
import java.util.HashSet;
import java.util.Set;

Set<String> set = new HashSet<>();

set.add("苹果");
set.add("香蕉");
set.add("橙子");
set.add("苹果");  // 重复，不会被添加

System.out.println(set);        // [香蕉, 苹果, 橙子]（顺序不定）
System.out.println(set.size()); // 3，不是 4

set.contains("苹果");  // true
set.remove("香蕉");
```

### 4.2 遍历 Set

```java
Set<String> set = new HashSet<>(Set.of("A", "B", "C"));

// 增强 for（最常用，但顺序不定）
for (String s : set) {
    System.out.println(s);
}

// forEach + Lambda
set.forEach(System.out::println);
```

### 4.3 LinkedHashSet（保持插入顺序）

```java
import java.util.LinkedHashSet;

Set<String> set = new LinkedHashSet<>();
set.add("橙子");
set.add("苹果");
set.add("香蕉");
set.add("苹果");  // 重复，忽略

System.out.println(set);  // [橙子, 苹果, 香蕉]（保持插入顺序）
```

### 4.4 TreeSet（自动排序）

```java
import java.util.TreeSet;

Set<Integer> set = new TreeSet<>();
set.add(5);
set.add(2);
set.add(8);
set.add(1);
set.add(2);  // 重复，忽略

System.out.println(set);  // [1, 2, 5, 8]（自动升序排列）
```

### 4.5 Set 的典型用途：去重

```java
// 去除列表中的重复元素
List<String> listWithDup = new ArrayList<>(
    List.of("苹果", "香蕉", "苹果", "橙子", "香蕉", "葡萄")
);

Set<String> set = new LinkedHashSet<>(listWithDup);  // 去重并保持顺序
List<String> deduped = new ArrayList<>(set);
System.out.println(deduped);  // [苹果, 香蕉, 橙子, 葡萄]
```

## 5. Map：键值对

### 5.1 HashMap 基本操作

```java
import java.util.HashMap;
import java.util.Map;

Map<String, Integer> scores = new HashMap<>();

// 添加 / 更新
scores.put("张三", 90);
scores.put("李四", 85);
scores.put("王五", 92);
scores.put("张三", 95);  // key 相同，覆盖旧值

System.out.println(scores);          // {李四=85, 张三=95, 王五=92}
System.out.println(scores.size());   // 3
```

### 5.2 获取与判断

```java
Map<String, Integer> scores = new HashMap<>();
scores.put("张三", 90);
scores.put("李四", 85);

// 获取
scores.get("张三");           // 90
scores.get("赵六");           // null（key 不存在）
scores.getOrDefault("赵六", 0); // 0（key 不存在时返回默认值）

// 判断
scores.containsKey("张三");   // true
scores.containsValue(85);     // true
scores.isEmpty();             // false
```

### 5.3 删除与更新

```java
Map<String, Integer> map = new HashMap<>();
map.put("A", 1);
map.put("B", 2);
map.put("C", 3);

// 删除
map.remove("B");              // 删除 key 为 B 的条目
map.remove("A", 1);          // 仅当值也匹配时才删除

// 更新
map.replace("C", 30);        // 替换
map.put("D", map.getOrDefault("D", 0) + 1);  // 不存在则初始化

// putIfAbsent：key 不存在时才放入
map.putIfAbsent("E", 5);
```

### 5.4 遍历 Map

```java
Map<String, Integer> scores = new HashMap<>();
scores.put("张三", 90);
scores.put("李四", 85);
scores.put("王五", 92);

// 方式一：遍历 entrySet（最常用，同时获取 key 和 value）
for (Map.Entry<String, Integer> entry : scores.entrySet()) {
    System.out.println(entry.getKey() + "：" + entry.getValue());
}

// 方式二：只遍历 key
for (String key : scores.keySet()) {
    System.out.println(key + "：" + scores.get(key));
}

// 方式三：只遍历 value
for (int value : scores.values()) {
    System.out.println(value);
}

// 方式四：forEach + Lambda（JDK 8+，最简洁）
scores.forEach((name, score) ->
    System.out.println(name + "：" + score));
```

### 5.5 LinkedHashMap 与 TreeMap

```java
// LinkedHashMap：保持插入顺序
Map<String, Integer> linked = new LinkedHashMap<>();
linked.put("C", 3);
linked.put("A", 1);
linked.put("B", 2);
System.out.println(linked);  // {C=3, A=1, B=2}（插入顺序）

// TreeMap：按 key 自然排序
Map<String, Integer> tree = new TreeMap<>();
tree.put("C", 3);
tree.put("A", 1);
tree.put("B", 2);
System.out.println(tree);    // {A=1, B=2, C=3}（字母序）
```

### 5.6 Map 的典型用途：统计频次

```java
String[] words = {"apple", "banana", "apple", "cherry", "banana", "apple"};

Map<String, Integer> freq = new HashMap<>();
for (String word : words) {
    freq.put(word, freq.getOrDefault(word, 0) + 1);
}

System.out.println(freq);
// {apple=3, banana=2, cherry=1}
```

## 6. 集合工具类 Collections

```java
import java.util.Collections;

List<Integer> list = new ArrayList<>(List.of(3, 1, 4, 1, 5, 9, 2, 6));

// 排序
Collections.sort(list);
System.out.println(list);  // [1, 1, 2, 3, 4, 5, 6, 9]

// 反转
Collections.reverse(list);
System.out.println(list);  // [9, 6, 5, 4, 3, 2, 1, 1]

// 随机打乱
Collections.shuffle(list);

// 最大值 / 最小值
System.out.println(Collections.max(list));
System.out.println(Collections.min(list));

// 出现次数
System.out.println(Collections.frequency(list, 1));  // 2

// 填充
Collections.fill(list, 0);  // 所有元素替换为 0

// 不可变包装（防止外部修改）
List<String> mutable = new ArrayList<>(List.of("A", "B", "C"));
List<String> immutable = Collections.unmodifiableList(mutable);
// immutable.add("D");  ❌ 运行时抛出 UnsupportedOperationException
```

## 7. 泛型基础

### 7.1 为什么需要泛型

```java
// 没有泛型（JDK 5 之前）
List list = new ArrayList();
list.add("字符串");
list.add(123);          // 什么都能放进去
list.add(new Object());

String s = (String) list.get(1);  // 运行时才报 ClassCastException！

// 有泛型（类型安全）
List<String> strList = new ArrayList<>();
strList.add("字符串");
strList.add(123);       // ❌ 编译直接报错，类型安全
String s2 = strList.get(0);  // 不需要强转
```

### 7.2 泛型语法

```java
// 泛型类
List<String> strings = new ArrayList<>();
Map<String, Integer> map = new HashMap<>();
Map<String, List<Integer>> nested = new HashMap<>();  // 嵌套泛型

// JDK 7+ 钻石操作符，右边可以省略类型
Map<String, Integer> m = new HashMap<>();  // 不需要写 new HashMap<String, Integer>()
```

### 7.3 常见泛型字母含义（约定俗成）

| 字母 | 含义                |
| ---- | ------------------- |
| `T`  | Type（类型）        |
| `E`  | Element（集合元素） |
| `K`  | Key（键）           |
| `V`  | Value（值）         |
| `N`  | Number（数字）      |

## 8. 和 JavaScript 的对比

### List vs JS 数组

```javascript
// JavaScript 数组
const list = [];
list.push("苹果");          // add
list.indexOf("苹果");       // indexOf
list.includes("苹果");      // contains
list.splice(1, 1);          // remove by index
list.length;                // size
list.forEach(x => ...);     // forEach
```

```java
// Java List
List<String> list = new ArrayList<>();
list.add("苹果");
list.indexOf("苹果");
list.contains("苹果");
list.remove(1);
list.size();
list.forEach(x -> ...);
```

方法名有些差异，但概念一一对应。

### Map vs JS 对象 / Map

```javascript
// JavaScript
const map = new Map();
map.set("key", "value");
map.get("key");
map.has("key");
map.delete("key");
map.size;
map.forEach((v, k) => ...);

// 或者直接用对象
const obj = { key: "value" };
obj["key"];
```

```java
// Java
Map<String, String> map = new HashMap<>();
map.put("key", "value");
map.get("key");
map.containsKey("key");
map.remove("key");
map.size();
map.forEach((k, v) -> ...);
```

### Set vs JS Set

```javascript
// JavaScript
const set = new Set();
set.add("A");
set.has("A");
set.delete("A");
set.size;
```

```java
// Java
Set<String> set = new HashSet<>();
set.add("A");
set.contains("A");
set.remove("A");
set.size();
```

| 特性     | Java 集合            | JavaScript            |
| -------- | -------------------- | --------------------- |
| 类型安全 | ✅ 泛型约束          | ❌ 任意类型混放       |
| 动态扩容 | ✅                   | ✅                    |
| 去重结构 | `HashSet`            | `Set`                 |
| 键值对   | `HashMap`            | `Map` 或对象          |
| 有序列表 | `ArrayList`          | 数组                  |
| 工具方法 | `Collections` 工具类 | 数组/Set/Map 自带方法 |

## 常见问题

**Q：`List.of()` 和 `new ArrayList<>()` 有什么区别？**  
A：`List.of()` 返回的是**不可变列表**，不能 `add`、`remove`、`set`，适合定义固定数据。`new ArrayList<>()` 是可变的。通常用 `new ArrayList<>(List.of(...))` 把不可变列表转成可变的。

**Q：什么时候用 `ArrayList`，什么时候用 `LinkedList`？**  
A：绝大多数情况用 `ArrayList`。只有在频繁在头部插入/删除，且数据量较大时才考虑 `LinkedList`。`LinkedList` 的随机访问（`get(i)`）是 O(n)，ArrayList 是 O(1)。

**Q：`HashMap` 的 key 可以是任意类型吗？**  
A：可以，但 key 对应的类必须正确实现 `hashCode()` 和 `equals()` 方法，否则查找结果不可靠。`String`、`Integer` 等内置类都已正确实现。自定义类做 key 时需要自己重写这两个方法。

**Q：`HashMap` 是线程安全的吗？**  
A：不是。多线程并发修改 `HashMap` 可能导致数据丢失甚至死循环（JDK 8 之前）。线程安全场景用 `ConcurrentHashMap`，1-15 多线程那节会讲。

**Q：遍历 List 时能直接删除元素吗？**  
A：不能直接在增强 for 循环里删除，会抛出 `ConcurrentModificationException`。要删除必须用迭代器（`Iterator`）的 `remove()` 方法，或者用 `removeIf()`：

```java
list.removeIf(s -> s.startsWith("A"));  // 删除所有以 A 开头的元素
```
