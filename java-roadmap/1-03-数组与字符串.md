## 1. 数组

数组是**固定长度、存储同一类型元素**的容器。和 JS 的数组不同，Java 数组一旦创建，长度不可改变。

### 1.1 声明与初始化

```java
// 方式一：声明 + 分配空间（元素默认值为 0 / false / null）
int[] scores = new int[5];       // 长度为 5 的 int 数组
String[] names = new String[3];  // 长度为 3 的字符串数组

// 方式二：声明 + 直接赋值
int[] ages = {18, 22, 25, 30};
String[] cities = {"北京", "上海", "广州", "深圳"};

// 方式三：new 关键字 + 赋值（和方式二等价）
int[] nums = new int[]{1, 2, 3, 4, 5};
```

### 1.2 访问与修改元素

```java
int[] scores = {90, 85, 78, 92, 88};

// 访问：下标从 0 开始
System.out.println(scores[0]);  // 90
System.out.println(scores[4]);  // 88

// 修改
scores[0] = 95;
System.out.println(scores[0]);  // 95

// 获取长度
System.out.println(scores.length);  // 5

// ⚠️ 越界访问会抛出异常
System.out.println(scores[5]);  // ArrayIndexOutOfBoundsException
```

### 1.3 遍历数组

```java
int[] nums = {10, 20, 30, 40, 50};

// 方式一：普通 for 循环（需要下标时用这个）
for (int i = 0; i < nums.length; i++) {
    System.out.println("下标 " + i + "：" + nums[i]);
}

// 方式二：增强 for 循环（for-each，只需要值时更简洁）
for (int num : nums) {
    System.out.println(num);
}
```

> **何时用哪种？**  
> 需要操作下标（如倒序、跳着访问）→ 普通 for  
> 只是遍历读取每个元素 → for-each，代码更简洁

## 2. 数组的常用操作

Java 提供了 `Arrays` 工具类，封装了常用的数组操作方法，使用前需要导入：

```java
import java.util.Arrays;
```

### 2.1 排序

```java
int[] nums = {5, 2, 8, 1, 9, 3};
Arrays.sort(nums);
System.out.println(Arrays.toString(nums));
// 输出：[1, 2, 3, 5, 8, 9]
```

### 2.2 打印数组

```java
int[] nums = {1, 2, 3};

// ❌ 直接打印只会输出地址信息
System.out.println(nums);          // [I@6d06d69c

// ✅ 用 Arrays.toString() 转成可读字符串
System.out.println(Arrays.toString(nums));  // [1, 2, 3]
```

### 2.3 复制数组

```java
int[] original = {1, 2, 3, 4, 5};

// 复制全部
int[] copy1 = Arrays.copyOf(original, original.length);

// 复制部分（下标 1 到 3，不包含 3）
int[] copy2 = Arrays.copyOfRange(original, 1, 3);
System.out.println(Arrays.toString(copy2));  // [2, 3]

// ⚠️ 直接赋值不是复制，是引用同一个数组
int[] ref = original;
ref[0] = 999;
System.out.println(original[0]);  // 999，original 也被修改了！
```

### 2.4 填充与查找

```java
int[] nums = new int[5];

// 填充：所有元素赋同一个值
Arrays.fill(nums, 7);
System.out.println(Arrays.toString(nums));  // [7, 7, 7, 7, 7]

// 二分查找（数组必须已排序）
int[] sorted = {1, 3, 5, 7, 9};
int index = Arrays.binarySearch(sorted, 5);
System.out.println(index);  // 2
```

### 2.5 数组作为方法参数

```java
public class ArrayDemo {
    public static void main(String[] args) {
        int[] scores = {88, 92, 75, 96, 83};
        System.out.println("最高分：" + getMax(scores));
        System.out.println("平均分：" + getAverage(scores));
    }

    // 求最大值
    static int getMax(int[] arr) {
        int max = arr[0];
        for (int num : arr) {
            if (num > max) max = num;
        }
        return max;
    }

    // 求平均值
    static double getAverage(int[] arr) {
        int sum = 0;
        for (int num : arr) {
            sum += num;
        }
        return (double) sum / arr.length;
    }
}
```

## 3. 多维数组

### 3.1 二维数组

可以理解为"数组的数组"，常用于表格、矩阵场景：

```java
// 声明 3 行 4 列的二维数组
int[][] matrix = new int[3][4];

// 直接初始化
int[][] grid = {
    {1, 2, 3},
    {4, 5, 6},
    {7, 8, 9}
};

// 访问元素：[行][列]
System.out.println(grid[0][0]);  // 1（第 0 行第 0 列）
System.out.println(grid[1][2]);  // 6（第 1 行第 2 列）

// 遍历二维数组
for (int i = 0; i < grid.length; i++) {
    for (int j = 0; j < grid[i].length; j++) {
        System.out.print(grid[i][j] + "\t");
    }
    System.out.println();
}
```

输出：

```
1	2	3
4	5	6
7	8	9
```

## 4. String 字符串

### 4.1 字符串的本质

`String` 是 Java 中最常用的类，本质上是**字符序列**，底层用 `char[]` 数组存储。

```java
String s1 = "hello";           // 推荐写法，字符串字面量
String s2 = new String("hello"); // 用构造方法创建
```

### 4.2 字符串不可变性

Java 的 `String` 是**不可变的（immutable）**，一旦创建，内容不能修改。

```java
String s = "hello";
s = s + " world";  // 并不是修改了原来的字符串
                   // 而是创建了一个新字符串 "hello world"
                   // 原来的 "hello" 还在内存里
```

这和 JS 的字符串一样——字符串操作都是返回新字符串，不修改原字符串。

### 4.3 字符串比较

```java
String a = "hello";
String b = "hello";
String c = new String("hello");

// == 比较的是内存地址
System.out.println(a == b);      // true（字面量会复用常量池）
System.out.println(a == c);      // false（new 出来的在堆上）

// equals() 比较的是内容 ✅
System.out.println(a.equals(c)); // true

// 忽略大小写比较
System.out.println("Hello".equalsIgnoreCase("hello")); // true
```

> **记住这条规则：字符串比较永远用 `.equals()`，不用 `==`。**

## 5. String 常用方法

```java
String s = "  Hello, Java World!  ";
```

### 5.1 基本信息

```java
s.length()          // 22，字符串长度（含空格）
s.isEmpty()         // false，是否为空字符串（length == 0）
s.isBlank()         // false，是否为空白字符串（JDK 11+，含纯空格情况）
s.charAt(7)         // 'J'，获取指定下标的字符
```

### 5.2 查找与判断

```java
String str = "Hello, Java World!";

str.contains("Java")         // true，是否包含子串
str.startsWith("Hello")      // true，是否以指定字符串开头
str.endsWith("!")            // true，是否以指定字符串结尾
str.indexOf("Java")          // 7，子串第一次出现的下标（找不到返回 -1）
str.lastIndexOf("o")         // 13，子串最后一次出现的下标
```

### 5.3 截取与分割

```java
String str = "Hello, Java World!";

// 截取子串
str.substring(7)      // "Java World!"（从下标 7 到结尾）
str.substring(7, 11)  // "Java"（下标 7 到 11，不含 11）

// 分割字符串
String csv = "苹果,香蕉,橙子,葡萄";
String[] fruits = csv.split(",");
// fruits = ["苹果", "香蕉", "橙子", "葡萄"]

// 多个分隔符用正则
String data = "a1b2c3d";
String[] parts = data.split("[0-9]");
// parts = ["a", "b", "c", "d"]
```

### 5.4 替换

```java
String str = "Hello, Java! Java is great!";

str.replace("Java", "Python")
// "Hello, Python! Python is great!"，替换所有匹配

str.replaceFirst("Java", "Python")
// "Hello, Python! Java is great!"，只替换第一个

str.replaceAll("\\s+", "-")
// 用正则替换所有空白为 -
```

### 5.5 大小写与去空格

```java
String str = "  Hello, Java!  ";

str.toUpperCase()   // "  HELLO, JAVA!  "
str.toLowerCase()   // "  hello, java!  "
str.trim()          // "Hello, Java!"，去掉首尾空白（不含中间）
str.strip()         // "Hello, Java!"，JDK 11+，更完善（支持 Unicode 空白）
```

### 5.6 拼接与格式化

```java
// 方式一：+ 运算符（少量拼接可用）
String name = "张三";
int age = 25;
String info = "姓名：" + name + "，年龄：" + age;

// 方式二：String.format()（格式化，类似 printf）
String info2 = String.format("姓名：%s，年龄：%d", name, age);

// 方式三：formatted()（JDK 15+，更简洁）
String info3 = "姓名：%s，年龄：%d".formatted(name, age);

// 方式四：String.join()（拼接数组 / 集合元素）
String result = String.join("-", "2026", "06", "19");
// "2026-06-19"
```

### 5.7 字符串与字符数组互转

```java
// String → char[]
String s = "hello";
char[] chars = s.toCharArray();
// chars = ['h', 'e', 'l', 'l', 'o']

// char[] → String
char[] arr = {'J', 'a', 'v', 'a'};
String str = new String(arr);
// str = "Java"
```

## 6. StringBuilder

### 6.1 为什么需要 StringBuilder

`String` 是不可变的，每次拼接都会创建新对象。循环内大量拼接时性能很差：

```java
// ❌ 性能差：每次循环都创建新的 String 对象
String result = "";
for (int i = 0; i < 10000; i++) {
    result += i;  // 产生 10000 个临时字符串对象
}

// ✅ 性能好：StringBuilder 在内部可变缓冲区上操作
StringBuilder sb = new StringBuilder();
for (int i = 0; i < 10000; i++) {
    sb.append(i);
}
String result = sb.toString();
```

### 6.2 StringBuilder 常用方法

```java
StringBuilder sb = new StringBuilder("Hello");

// 追加（支持各种类型）
sb.append(", ");
sb.append("Java");
sb.append("!");
System.out.println(sb);  // Hello, Java!

// 插入
sb.insert(5, " World");
System.out.println(sb);  // Hello World, Java!

// 删除
sb.delete(5, 11);        // 删除下标 5 到 11（不含 11）
System.out.println(sb);  // Hello, Java!

// 替换
sb.replace(7, 11, "Python");
System.out.println(sb);  // Hello, Python!

// 反转
sb.reverse();
System.out.println(sb);  // !nohtyP ,olleH

// 转为 String
String result = sb.toString();
```

### 6.3 链式调用

StringBuilder 的方法都返回自身，支持链式调用：

```java
String result = new StringBuilder()
    .append("Hello")
    .append(", ")
    .append("Java")
    .append("!")
    .toString();
// "Hello, Java!"
```

> **StringBuffer vs StringBuilder：**  
> `StringBuffer` 是线程安全版本，方法加了 `synchronized`，性能略差。单线程环境下统一用 `StringBuilder`。

## 7. 和 JavaScript 的对比

### 数组对比

| 特性 | Java 数组                | JavaScript 数组      |
| ---- | ------------------------ | -------------------- |
| 长度 | 固定，创建后不可改变     | 动态，可随时增减     |
| 类型 | 同一类型                 | 任意混合类型         |
| 打印 | 需要 `Arrays.toString()` | 直接 `console.log()` |
| 越界 | 抛出异常                 | 返回 `undefined`     |
| 排序 | `Arrays.sort()`          | `arr.sort()`         |

Java 数组功能相对有限，实际开发中更多用 `ArrayList`（类似 JS 数组），1-07 集合章节会重点讲。

### 字符串对比

| 特性     | Java String              | JavaScript String    |
| -------- | ------------------------ | -------------------- |
| 不可变性 | ✅ 不可变                | ✅ 不可变            |
| 比较方式 | `.equals()`，不用 `==`   | `===`                |
| 长度     | `.length()`（方法）      | `.length`（属性）    |
| 截取     | `.substring(start, end)` | `.slice(start, end)` |
| 分割     | `.split(分隔符)`         | `.split(分隔符)`     |
| 包含     | `.contains()`            | `.includes()`        |
| 查找     | `.indexOf()`             | `.indexOf()`         |
| 格式化   | `String.format()`        | 模板字符串 \`${}\`   |

**最容易踩的坑：**

```java
// 坑 1：length 是方法不是属性
String s = "hello";
s.length   // ❌ 编译报错
s.length() // ✅

// 坑 2：直接打印数组
int[] arr = {1, 2, 3};
System.out.println(arr);              // ❌ 输出地址
System.out.println(Arrays.toString(arr)); // ✅

// 坑 3：循环内用 + 拼接字符串
for (int i = 0; i < 1000; i++) {
    result += i;  // ❌ 性能极差
}
// ✅ 用 StringBuilder
```

## 常见问题

**Q：Java 有没有类似 JS 的 `arr.push()`、`arr.pop()` 方法？**  
A：数组没有，但 `ArrayList` 有类似的 `add()` 和 `remove()`。实际开发中需要动态增删元素时都用 `ArrayList`，1-07 会详细讲。

**Q：字符串为什么要设计成不可变的？**  
A：三个原因：安全性（字符串常用于密码、网络地址，不可变防止被篡改）、线程安全（多线程共享时无需加锁）、性能（JVM 可以将相同字符串字面量存在常量池中复用）。

**Q：`String.format()` 里的 `%s`、`%d` 都有哪些？**  
A：常用的：`%s` 字符串、`%d` 整数、`%f` 浮点数（`%.2f` 保留两位小数）、`%n` 换行、`%b` 布尔值。

**Q：`substring` 的下标总是记不住，有什么规律？**  
A：Java 里区间基本都是**左闭右开**——`substring(start, end)` 包含 `start`，不包含 `end`。`copyOfRange`、`delete`、`List.subList` 都是一样的规律，记住这一条就够了。
