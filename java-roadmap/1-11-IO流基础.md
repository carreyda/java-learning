## 1. IO 流概述

IO 是 Input/Output（输入/输出）的缩写。Java 用"流"的概念来描述数据的流动：

```
数据源（文件、网络、键盘...）
        ↓  输入流（InputStream / Reader）
      程序
        ↓  输出流（OutputStream / Writer）
数据目标（文件、网络、屏幕...）
```

### 1.1 流的分类

| 维度 | 分类           | 代表类                                |
| ---- | -------------- | ------------------------------------- |
| 方向 | 输入流         | `InputStream`、`Reader`               |
| 方向 | 输出流         | `OutputStream`、`Writer`              |
| 单位 | 字节流（8位）  | `InputStream`、`OutputStream`         |
| 单位 | 字符流（16位） | `Reader`、`Writer`                    |
| 功能 | 节点流         | `FileInputStream`、`FileReader`       |
| 功能 | 包装流         | `BufferedReader`、`InputStreamReader` |

**选哪种流：**

- 文本文件（`.txt`、`.csv`、`.json`）→ 字符流
- 二进制文件（图片、音视频、压缩包）→ 字节流
- 追求性能 → 加缓冲流包装

### 1.2 流的体系

```
字节流
  InputStream（抽象）
    └── FileInputStream          读文件
  OutputStream（抽象）
    └── FileOutputStream         写文件

字符流
  Reader（抽象）
    ├── FileReader               读文本文件
    └── InputStreamReader        字节流 → 字符流（转换流）
  Writer（抽象）
    ├── FileWriter               写文本文件
    └── OutputStreamWriter       字符流 → 字节流（转换流）

缓冲流（包装上面的流，提升性能）
  BufferedInputStream / BufferedOutputStream
  BufferedReader / BufferedWriter
```

## 2. File 类

`File` 类代表文件或目录路径，**不是用来读写内容的**，而是用来操作文件的元信息（是否存在、创建、删除、列出目录等）。

```java
import java.io.File;

// 创建 File 对象（此时文件不一定存在）
File file = new File("test.txt");
File file2 = new File("D:/data/test.txt");  // 绝对路径
File dir = new File("src/main/resources");  // 目录
```

### 2.1 文件信息

```java
File file = new File("test.txt");

file.exists();          // 是否存在
file.isFile();          // 是否是文件
file.isDirectory();     // 是否是目录
file.getName();         // 文件名：test.txt
file.getPath();         // 相对路径：test.txt
file.getAbsolutePath(); // 绝对路径：D:\project\test.txt
file.length();          // 文件大小（字节数）
file.lastModified();    // 最后修改时间（时间戳）
file.canRead();         // 是否可读
file.canWrite();        // 是否可写
```

### 2.2 创建与删除

```java
File file = new File("test.txt");

// 创建文件（父目录必须存在）
boolean created = file.createNewFile();  // 成功返回 true

// 创建目录
File dir = new File("output/logs");
dir.mkdir();    // 只创建最后一级目录（父目录不存在则失败）
dir.mkdirs();   // 递归创建所有不存在的目录

// 删除（目录必须为空才能删除）
file.delete();

// 重命名 / 移动
File newFile = new File("renamed.txt");
file.renameTo(newFile);
```

### 2.3 目录操作

```java
File dir = new File("src");

// 列出目录内容
String[] names = dir.list();          // 返回文件名数组
File[] files = dir.listFiles();       // 返回 File 对象数组

// 过滤：只列出 .java 文件
File[] javaFiles = dir.listFiles(f -> f.getName().endsWith(".java"));

// 遍历目录（包含子目录）
void listAll(File dir, int depth) {
    File[] files = dir.listFiles();
    if (files == null) return;
    for (File f : files) {
        System.out.println("  ".repeat(depth) + f.getName());
        if (f.isDirectory()) {
            listAll(f, depth + 1);  // 递归
        }
    }
}
```

## 3. 字节流

字节流处理所有类型的数据，每次读写 1 个字节（8位）。

### 3.1 FileOutputStream（写文件）

```java
import java.io.FileOutputStream;

// 写入字节数组
try (FileOutputStream fos = new FileOutputStream("output.txt")) {
    String content = "Hello, Java IO!";
    byte[] bytes = content.getBytes("UTF-8");  // 字符串 → 字节数组
    fos.write(bytes);
    System.out.println("写入成功");
} catch (IOException e) {
    e.printStackTrace();
}

// 追加模式（第二个参数 true = 追加，false = 覆盖）
try (FileOutputStream fos = new FileOutputStream("output.txt", true)) {
    fos.write("\n追加的内容".getBytes("UTF-8"));
}
```

### 3.2 FileInputStream（读文件）

```java
import java.io.FileInputStream;

// 方式一：逐字节读（效率低，不推荐）
try (FileInputStream fis = new FileInputStream("output.txt")) {
    int b;
    while ((b = fis.read()) != -1) {  // -1 表示读到文件末尾
        System.out.print((char) b);
    }
}

// 方式二：按缓冲区读（推荐）
try (FileInputStream fis = new FileInputStream("output.txt")) {
    byte[] buffer = new byte[1024];  // 每次最多读 1024 字节
    int len;
    StringBuilder sb = new StringBuilder();
    while ((len = fis.read(buffer)) != -1) {
        sb.append(new String(buffer, 0, len, "UTF-8"));
    }
    System.out.println(sb.toString());
}
```

### 3.3 文件复制（字节流）

```java
public static void copyFile(String src, String dest) throws IOException {
    try (
        FileInputStream fis = new FileInputStream(src);
        FileOutputStream fos = new FileOutputStream(dest)
    ) {
        byte[] buffer = new byte[8192];  // 8KB 缓冲区
        int len;
        while ((len = fis.read(buffer)) != -1) {
            fos.write(buffer, 0, len);
        }
    }
}
```

## 4. 字符流

字符流处理文本数据，自动处理字符编码，每次读写 1 个字符（16位）。

### 4.1 FileWriter（写文本文件）

```java
import java.io.FileWriter;

// 写入字符串
try (FileWriter fw = new FileWriter("text.txt", java.nio.charset.StandardCharsets.UTF_8)) {
    fw.write("第一行内容\n");
    fw.write("第二行内容\n");
    fw.write("第三行内容\n");
}

// 追加模式
try (FileWriter fw = new FileWriter("text.txt", true)) {
    fw.write("追加的内容\n");
}
```

### 4.2 FileReader（读文本文件）

```java
import java.io.FileReader;

// 逐字符读
try (FileReader fr = new FileReader("text.txt")) {
    int c;
    while ((c = fr.read()) != -1) {
        System.out.print((char) c);
    }
}

// 按缓冲区读
try (FileReader fr = new FileReader("text.txt")) {
    char[] buffer = new char[1024];
    int len;
    StringBuilder sb = new StringBuilder();
    while ((len = fr.read(buffer)) != -1) {
        sb.append(buffer, 0, len);
    }
    System.out.println(sb.toString());
}
```

## 5. 缓冲流

缓冲流在内存中维护一个缓冲区，减少实际 IO 次数，大幅提升读写性能。

### 5.1 BufferedWriter（按行写）

```java
import java.io.BufferedWriter;
import java.io.FileWriter;

try (BufferedWriter bw = new BufferedWriter(new FileWriter("text.txt"))) {
    bw.write("第一行");
    bw.newLine();  // 写入平台相关的换行符（比 \n 更兼容）
    bw.write("第二行");
    bw.newLine();
    bw.write("第三行");
    // close() 时自动 flush()，确保缓冲区内容写入文件
}
```

### 5.2 BufferedReader（按行读）

```java
import java.io.BufferedReader;
import java.io.FileReader;

// 逐行读取（最常用的文本读取方式）
try (BufferedReader br = new BufferedReader(new FileReader("text.txt"))) {
    String line;
    while ((line = br.readLine()) != -1 && line != null) {
        System.out.println(line);
    }
}

// JDK 8+：用 lines() 方法返回 Stream，更简洁
try (BufferedReader br = new BufferedReader(new FileReader("text.txt"))) {
    br.lines().forEach(System.out::println);
}
```

### 5.3 性能对比

```java
// 不加缓冲：每次 write 都触发一次系统调用
FileWriter fw = new FileWriter("test.txt");

// 加缓冲：写入缓冲区，积累到一定量再批量写入，性能提升明显
BufferedWriter bw = new BufferedWriter(new FileWriter("test.txt"));

// 写 10 万行数据的性能差异（大致）：
// 无缓冲：可能需要数秒
// 有缓冲：通常几十毫秒
```

## 6. 常用工具操作

### 6.1 一次性读取整个文件（NIO，JDK 7+）

```java
import java.nio.file.Files;
import java.nio.file.Path;
import java.nio.file.Paths;

// 读取所有字节
byte[] bytes = Files.readAllBytes(Paths.get("image.png"));

// 读取所有行（返回 List<String>）
List<String> lines = Files.readAllLines(Paths.get("text.txt"),
    StandardCharsets.UTF_8);
lines.forEach(System.out::println);

// 读取为字符串（JDK 11+）
String content = Files.readString(Paths.get("text.txt"), StandardCharsets.UTF_8);
System.out.println(content);
```

### 6.2 一次性写入文件（NIO）

```java
// 写入字节数组
Files.write(Paths.get("output.bin"), bytes);

// 写入字符串列表（每个元素占一行）
List<String> lines = List.of("第一行", "第二行", "第三行");
Files.write(Paths.get("output.txt"), lines, StandardCharsets.UTF_8);

// 写入字符串（JDK 11+）
Files.writeString(Paths.get("output.txt"), "Hello, NIO!", StandardCharsets.UTF_8);

// 追加写入
Files.writeString(Paths.get("output.txt"), "\n追加内容",
    StandardCharsets.UTF_8, StandardOpenOption.APPEND);
```

### 6.3 文件操作（NIO Files 工具类）

```java
Path src = Paths.get("source.txt");
Path dest = Paths.get("dest.txt");

// 复制文件
Files.copy(src, dest);
Files.copy(src, dest, StandardCopyOption.REPLACE_EXISTING);  // 覆盖已存在

// 移动 / 重命名
Files.move(src, dest);

// 删除
Files.delete(src);                   // 不存在时抛异常
Files.deleteIfExists(src);           // 不存在时静默忽略

// 创建目录
Files.createDirectory(Paths.get("newDir"));
Files.createDirectories(Paths.get("a/b/c"));  // 递归创建

// 判断
Files.exists(src);
Files.isDirectory(src);
Files.size(src);
```

### 6.4 CSV 文件读写示例

```java
// 写 CSV
public static void writeCsv(String path, List<String[]> rows) throws IOException {
    try (BufferedWriter bw = new BufferedWriter(
            new FileWriter(path, StandardCharsets.UTF_8))) {
        for (String[] row : rows) {
            bw.write(String.join(",", row));
            bw.newLine();
        }
    }
}

// 读 CSV
public static List<String[]> readCsv(String path) throws IOException {
    List<String[]> result = new ArrayList<>();
    try (BufferedReader br = new BufferedReader(
            new FileReader(path, StandardCharsets.UTF_8))) {
        String line;
        while ((line = br.readLine()) != null) {
            result.add(line.split(","));
        }
    }
    return result;
}

// 使用示例
List<String[]> data = List.of(
    new String[]{"学号", "姓名", "成绩"},
    new String[]{"S0001", "张三", "92"},
    new String[]{"S0002", "李四", "88"}
);
writeCsv("students.csv", data);

List<String[]> loaded = readCsv("students.csv");
loaded.forEach(row -> System.out.println(Arrays.toString(row)));
```

## 7. 和 JavaScript 的对比

Node.js 里也有文件读写 API，概念类似但语法不同：

```javascript
// Node.js 同步读写
const fs = require("fs");

// 读取全部内容
const content = fs.readFileSync("text.txt", "utf8");

// 按行读（需要 readline）
const readline = require("readline");
const rl = readline.createInterface({ input: fs.createReadStream("text.txt") });
rl.on("line", (line) => console.log(line));

// 写文件
fs.writeFileSync("output.txt", "Hello!", "utf8");

// 追加
fs.appendFileSync("output.txt", "\n追加内容");
```

```java
// Java 等价写法
// 读取全部内容
String content = Files.readString(Paths.get("text.txt"), StandardCharsets.UTF_8);

// 按行读
Files.readAllLines(Paths.get("text.txt"), StandardCharsets.UTF_8)
     .forEach(System.out::println);

// 写文件
Files.writeString(Paths.get("output.txt"), "Hello!", StandardCharsets.UTF_8);

// 追加
Files.writeString(Paths.get("output.txt"), "\n追加内容",
    StandardCharsets.UTF_8, StandardOpenOption.APPEND);
```

| 特性     | Java                      | Node.js                  |
| -------- | ------------------------- | ------------------------ |
| 同步读写 | 默认同步                  | 需要加 `Sync` 后缀       |
| 异步读写 | 需要 NIO 或线程           | 默认异步（回调/Promise） |
| 字符编码 | 显式指定（推荐）          | 可选                     |
| 路径操作 | `Paths`、`File`           | `path` 模块              |
| 流式读写 | `BufferedReader`/`Writer` | `fs.createReadStream`    |

**主要差异：** Node.js 默认异步非阻塞，Java IO 默认同步阻塞。后端开发中 Java 通过多线程处理并发，不像 Node.js 那样依赖事件循环。

## 常见问题

**Q：字节流和字符流有什么实质区别？**  
A：字节流每次读写 1 个字节（8位），不处理编码，适合所有文件类型。字符流每次读写 1 个字符（Java 中是 16 位 Unicode），内部自动做编码转换，适合文本文件。读取中文时用字节流可能乱码，字符流会自动按指定编码处理。

**Q：为什么文件操作要用 UTF-8 编码？**  
A：Java 默认编码依赖操作系统设置，Windows 中文系统默认是 GBK，可能导致中文乱码。**永远显式指定 `StandardCharsets.UTF_8`** 是最安全的做法，跨平台不会出问题。

**Q：`flush()` 是什么，什么时候需要调用？**  
A：缓冲流会把数据先暂存在内存缓冲区，`flush()` 强制把缓冲区内容写入底层目标。使用 try-with-resources 时，`close()` 会自动调用 `flush()`，通常不需要手动调用。但如果你想在流还没关闭的时候确保数据已写入，可以手动调 `flush()`。

**Q：NIO 的 `Files` 工具类和传统 IO 有什么关系？**  
A：`java.nio.file.Files` 是 JDK 7 引入的新文件操作 API，封装了常用操作，使用更简洁。对于简单的文件读写，推荐直接用 NIO 的 `Files.readString()`、`Files.writeString()` 等方法。传统 IO 流在需要流式处理大文件（不一次性读入内存）时仍然有用。

**Q：读取大文件时怎么避免内存溢出？**  
A：不要用 `Files.readAllBytes()` 或 `Files.readAllLines()` 一次读入全部内容，而是用流式读取：

```java
try (BufferedReader br = new BufferedReader(new FileReader("bigfile.txt"))) {
    String line;
    while ((line = br.readLine()) != null) {
        // 逐行处理，内存里只有一行
    }
}
```
