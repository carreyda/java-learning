## 1. 继承

### 1.1 为什么需要继承

假设要定义"学生"和"教师"两个类：

```java
// 没有继承时，大量代码重复
public class Student {
    private String name;
    private int age;
    private String email;
    // 学生特有
    private String studentId;
    private double gpa;
}

public class Teacher {
    private String name;   // 重复！
    private int age;       // 重复！
    private String email;  // 重复！
    // 教师特有
    private String teacherId;
    private String subject;
}
```

`name`、`age`、`email` 在两个类里重复定义，维护麻烦。继承可以把公共部分抽取到父类。

### 1.2 继承的写法

用 `extends` 关键字：

```java
// 父类（基类）：抽取公共属性和方法
public class Person {
    private String name;
    private int age;
    private String email;

    public Person(String name, int age, String email) {
        this.name = name;
        this.age = age;
        this.email = email;
    }

    public String getName() { return name; }
    public int getAge() { return age; }
    public String getEmail() { return email; }

    public void introduce() {
        System.out.println("我叫 " + name + "，" + age + " 岁");
    }
}

// 子类：继承 Person，只写自己特有的部分
public class Student extends Person {
    private String studentId;
    private double gpa;

    public Student(String name, int age, String email, String studentId, double gpa) {
        super(name, age, email);  // 调用父类构造方法
        this.studentId = studentId;
        this.gpa = gpa;
    }

    public void study() {
        System.out.println(getName() + " 正在学习，GPA：" + gpa);
    }
}

public class Teacher extends Person {
    private String teacherId;
    private String subject;

    public Teacher(String name, int age, String email, String teacherId, String subject) {
        super(name, age, email);
        this.teacherId = teacherId;
        this.subject = subject;
    }

    public void teach() {
        System.out.println(getName() + " 正在教 " + subject);
    }
}
```

```java
Student s = new Student("张三", 20, "zs@email.com", "S001", 3.8);
s.introduce();  // 我叫 张三，20 岁（继承自 Person）
s.study();      // 张三 正在学习，GPA：3.8（Student 自己的方法）

Teacher t = new Teacher("王老师", 40, "wls@email.com", "T001", "Java");
t.introduce();  // 我叫 王老师，40 岁
t.teach();      // 王老师 正在教 Java
```

### 1.3 继承的特点

- Java 只支持**单继承**，一个类只能有一个父类（但可以实现多个接口）
- 子类继承父类所有非 `private` 的属性和方法
- 子类可以新增自己的属性和方法
- 所有类都隐式继承自 `Object` 类（Java 的根类）

### 1.4 继承链

```
Object
  └── Person
        ├── Student
        └── Teacher
```

`Student` 的对象同时也是 `Person`，也是 `Object`。可以用 `instanceof` 判断：

```java
Student s = new Student(...);
System.out.println(s instanceof Student);  // true
System.out.println(s instanceof Person);   // true
System.out.println(s instanceof Object);   // true
```

## 2. 方法重写

### 2.1 什么是重写（Override）

子类对父类方法的重新实现，叫做**方法重写**。用 `@Override` 注解标注（不是强制，但强烈建议写）。

```java
public class Person {
    private String name;

    public Person(String name) {
        this.name = name;
    }

    public String getName() { return name; }

    public void introduce() {
        System.out.println("我叫 " + name);
    }
}

public class Student extends Person {
    private String studentId;

    public Student(String name, String studentId) {
        super(name);
        this.studentId = studentId;
    }

    @Override
    public void introduce() {
        // 调用父类版本，再追加自己的信息
        super.introduce();
        System.out.println("学号：" + studentId);
    }
}
```

```java
Person p = new Person("张三");
p.introduce();
// 我叫 张三

Student s = new Student("李四", "S001");
s.introduce();
// 我叫 李四
// 学号：S001
```

### 2.2 重写 vs 重载

| 对比        | 重写（Override）     | 重载（Overload） |
| ----------- | -------------------- | ---------------- |
| 位置        | 子类重写父类方法     | 同一个类里       |
| 方法名      | 相同                 | 相同             |
| 参数列表    | 必须相同             | 必须不同         |
| 返回值      | 必须相同（或子类型） | 无要求           |
| `@Override` | 建议标注             | 不需要           |

### 2.3 重写 Object 的方法

`Object` 类有几个方法几乎每个类都应该重写：

```java
public class Person {
    private String name;
    private int age;

    public Person(String name, int age) {
        this.name = name;
        this.age = age;
    }

    // 重写 toString：打印对象时输出可读信息
    @Override
    public String toString() {
        return "Person{name='" + name + "', age=" + age + "}";
    }

    // 重写 equals：定义"相等"的逻辑
    @Override
    public boolean equals(Object obj) {
        if (this == obj) return true;
        if (!(obj instanceof Person)) return false;
        Person other = (Person) obj;
        return this.age == other.age && this.name.equals(other.name);
    }
}
```

```java
Person p1 = new Person("张三", 25);
Person p2 = new Person("张三", 25);

System.out.println(p1);           // Person{name='张三', age=25}
System.out.println(p1.equals(p2)); // true（内容相同）
System.out.println(p1 == p2);      // false（不同对象）
```

## 3. super 关键字

`super` 代表父类，有两种用法：

### 3.1 调用父类构造方法

```java
public class Animal {
    private String name;
    private String species;

    public Animal(String name, String species) {
        this.name = name;
        this.species = species;
    }
}

public class Dog extends Animal {
    private String breed;  // 品种

    public Dog(String name, String breed) {
        super(name, "犬科");  // 必须是第一行
        this.breed = breed;
    }
}
```

> `super()` 必须是子类构造方法的**第一行**。如果没有显式调用，Java 会自动调用父类的无参构造方法（如果父类没有无参构造就报错）。

### 3.2 调用父类的方法或属性

```java
public class Animal {
    public void makeSound() {
        System.out.println("动物发出声音");
    }
}

public class Dog extends Animal {
    @Override
    public void makeSound() {
        super.makeSound();       // 先调用父类的版本
        System.out.println("汪汪汪！");  // 再追加自己的
    }
}
```

## 4. final 关键字

`final` 在 OOP 中的用途：

```java
// 1. final 类：不能被继承
public final class String { ... }  // Java 内置的 String 就是 final 的

// 2. final 方法：不能被子类重写
public class Person {
    public final void breathe() {
        System.out.println("呼吸");  // 所有人都一样，不允许重写
    }
}

// 3. final 变量：常量，赋值后不能修改
public class Circle {
    public static final double PI = 3.14159265358979;
}
```

## 5. 多态

### 5.1 什么是多态

**同一个引用类型，指向不同的对象，调用同一个方法，产生不同的结果。**

多态的前提：继承 + 方法重写 + 父类引用指向子类对象。

```java
public class Animal {
    private String name;

    public Animal(String name) {
        this.name = name;
    }

    public String getName() { return name; }

    public void makeSound() {
        System.out.println(name + " 发出声音");
    }
}

public class Dog extends Animal {
    public Dog(String name) { super(name); }

    @Override
    public void makeSound() {
        System.out.println(getName() + "：汪汪汪！");
    }
}

public class Cat extends Animal {
    public Cat(String name) { super(name); }

    @Override
    public void makeSound() {
        System.out.println(getName() + "：喵喵喵～");
    }
}

public class Duck extends Animal {
    public Duck(String name) { super(name); }

    @Override
    public void makeSound() {
        System.out.println(getName() + "：嘎嘎嘎！");
    }
}
```

```java
// 父类引用指向子类对象
Animal a1 = new Dog("小黑");
Animal a2 = new Cat("小白");
Animal a3 = new Duck("唐老鸭");

// 调用同一个方法，结果不同 —— 这就是多态
a1.makeSound();  // 小黑：汪汪汪！
a2.makeSound();  // 小白：喵喵喵～
a3.makeSound();  // 唐老鸭：嘎嘎嘎！
```

### 5.2 多态的真正价值：统一处理

```java
// 用数组统一管理所有动物
Animal[] animals = {
    new Dog("小黑"),
    new Cat("小白"),
    new Duck("唐老鸭"),
    new Dog("旺财")
};

// 统一调用，不需要判断具体类型
for (Animal animal : animals) {
    animal.makeSound();
}
```

不用多态的话，需要写大量 `if-else` 判断类型，每新增一种动物都要改代码。有了多态，新增 `Bird` 类只需继承 `Animal` 并重写 `makeSound()`，调用代码一行都不用改。

### 5.3 向上转型与向下转型

```java
// 向上转型（自动，安全）：子类对象赋给父类引用
Animal a = new Dog("小黑");  // 自动向上转型
a.makeSound();  // ✅ 调用 Dog 的 makeSound

// 向上转型后，只能调用父类定义的方法
// a.fetch();  ❌ 编译报错，Animal 没有 fetch() 方法

// 向下转型（强制，需要先判断）
if (a instanceof Dog) {
    Dog dog = (Dog) a;  // 强制向下转型
    dog.fetch();        // ✅ 现在可以调用 Dog 特有的方法
}

// JDK 16+ 模式匹配 instanceof，更简洁
if (a instanceof Dog dog) {
    dog.fetch();  // 直接用，不需要单独写强转
}
```

## 6. 抽象类

### 6.1 为什么需要抽象类

`Animal` 的 `makeSound()` 方法在父类里其实没有实际意义——"动物发出声音"这个默认实现毫无用处，而且容易误用。我们希望**强制每个子类必须实现自己的叫声**，这时就用抽象类。

### 6.2 抽象类的写法

```java
// abstract 修饰类
public abstract class Animal {
    private String name;

    public Animal(String name) {
        this.name = name;
    }

    public String getName() { return name; }

    // abstract 修饰方法：只有声明，没有方法体
    // 子类必须实现，否则编译报错
    public abstract void makeSound();

    // 抽象类可以有普通方法
    public void sleep() {
        System.out.println(name + " 正在睡觉");
    }
}
```

```java
public class Dog extends Animal {
    public Dog(String name) { super(name); }

    @Override
    public void makeSound() {
        System.out.println(getName() + "：汪汪汪！");
    }
    // 如果不实现 makeSound()，编译直接报错
}
```

```java
// Animal a = new Animal("动物");  ❌ 抽象类不能实例化
Animal a = new Dog("小黑");        // ✅ 只能用子类实例化
a.makeSound();  // 小黑：汪汪汪！
a.sleep();      // 小黑 正在睡觉
```

### 6.3 抽象类的特点

- 用 `abstract` 修饰
- **不能被实例化**（不能 `new`）
- 可以有抽象方法（没有方法体），也可以有普通方法
- 子类必须实现所有抽象方法（除非子类也是抽象类）
- 可以有构造方法（供子类 `super()` 调用）

## 7. 接口

### 7.1 什么是接口

接口（Interface）是**纯粹的行为规范**，定义"能做什么"，不关心"怎么做"。

现实类比：USB 接口定义了插槽规格，不管是鼠标还是键盘，只要符合规格就能用。

### 7.2 接口的写法

```java
// 定义接口
public interface Flyable {
    // 接口里的方法默认是 public abstract，不用写
    void fly();
    void land();

    // JDK 8+ 可以有默认方法（有方法体）
    default void glide() {
        System.out.println("正在滑翔");
    }

    // JDK 8+ 可以有静态方法
    static void checkWeather() {
        System.out.println("检查飞行天气");
    }
}

public interface Swimmable {
    void swim();
    void dive();
}
```

```java
// 实现接口用 implements，可以同时实现多个接口
public class Duck extends Animal implements Flyable, Swimmable {

    public Duck(String name) { super(name); }

    @Override
    public void makeSound() {
        System.out.println(getName() + "：嘎嘎嘎！");
    }

    @Override
    public void fly() {
        System.out.println(getName() + " 在飞翔");
    }

    @Override
    public void land() {
        System.out.println(getName() + " 降落了");
    }

    @Override
    public void swim() {
        System.out.println(getName() + " 在游泳");
    }

    @Override
    public void dive() {
        System.out.println(getName() + " 在潜水");
    }
}
```

```java
Duck duck = new Duck("唐老鸭");

// 可以用不同接口类型引用
Flyable f = duck;
f.fly();    // 唐老鸭 在飞翔
f.glide();  // 正在滑翔（默认方法）

Swimmable s = duck;
s.swim();   // 唐老鸭 在游泳

Flyable.checkWeather();  // 检查飞行天气（静态方法用接口名调用）
```

### 7.3 接口的特点

- 用 `interface` 定义，用 `implements` 实现
- 一个类可以实现**多个接口**（解决 Java 单继承的限制）
- 接口不能实例化
- 接口里的变量默认是 `public static final`（常量）
- JDK 8+ 支持 `default` 方法和 `static` 方法

## 8. 抽象类 vs 接口

这是面试高频题，必须说清楚：

| 对比项   | 抽象类                    | 接口                              |
| -------- | ------------------------- | --------------------------------- |
| 关键字   | `abstract class`          | `interface`                       |
| 实现方式 | `extends`（单继承）       | `implements`（可多实现）          |
| 构造方法 | 有                        | 无                                |
| 成员变量 | 任意类型                  | 只能是 `public static final` 常量 |
| 普通方法 | 可以有                    | JDK 8+ 可以有 `default` 方法      |
| 抽象方法 | 可以有（`abstract` 修饰） | 默认都是抽象的                    |
| 使用场景 | **is-a 关系**，共享代码   | **can-do 关系**，定义能力         |

**一句话记忆：**

- 抽象类：**同类事物的公共模板**（Dog、Cat、Duck 都是 Animal）
- 接口：**跨类事物的能力约定**（Duck 能飞也能游，Airplane 也能飞，但它们不是同一类）

**设计示例：**

```
Animal（抽象类）
  ├── Dog（extends Animal）
  ├── Cat（extends Animal）
  └── Duck（extends Animal, implements Flyable, Swimmable）

Airplane（extends Vehicle, implements Flyable）
Bird（extends Animal, implements Flyable）
```

`Duck`、`Airplane`、`Bird` 都能飞，但它们继承体系完全不同。用接口 `Flyable` 就能统一处理：

```java
Flyable[] flyThings = {new Duck("唐老鸭"), new Bird("老鹰"), new Airplane("波音747")};
for (Flyable f : flyThings) {
    f.fly();
}
```

## 9. 和 JavaScript 的对比

### 继承

```javascript
// JavaScript
class Animal {
  constructor(name) {
    this.name = name;
  }
  makeSound() {
    console.log(`${this.name} 发出声音`);
  }
}

class Dog extends Animal {
  makeSound() {
    super.makeSound(); // 调用父类
    console.log(`${this.name}：汪汪！`);
  }
}
```

```java
// Java
public class Animal {
    private String name;
    public Animal(String name) { this.name = name; }
    public void makeSound() { System.out.println(name + " 发出声音"); }
}

public class Dog extends Animal {
    public Dog(String name) { super(name); }  // super() 必须第一行

    @Override  // 必须显式标注
    public void makeSound() {
        super.makeSound();
        System.out.println(getName() + "：汪汪！");
    }
}
```

### 接口 vs JS 的 Mixin

JS 没有原生接口概念，通常用 Mixin 模式模拟多继承。Java 的接口是语言级别的强约束，实现类必须提供所有方法，否则编译不通过。

| 特性     | Java                 | JavaScript                  |
| -------- | -------------------- | --------------------------- |
| 继承     | 单继承（`extends`）  | 单继承（`extends`）         |
| 多实现   | 接口（`implements`） | Mixin / 无原生支持          |
| 抽象类   | `abstract class`     | 无原生支持                  |
| 接口     | `interface`          | 无原生支持（TypeScript 有） |
| 强制实现 | 编译时检查           | 无强制，运行时才知道        |

## 常见问题

**Q：Java 为什么不支持多继承？**  
A：多继承会导致"菱形问题"——如果 B 和 C 都继承 A，D 同时继承 B 和 C，且 B、C 都重写了 A 的方法，D 调用该方法时不知道用哪个版本。Java 用接口的 `default` 方法替代多继承，规避了这个问题。

**Q：接口里的 `default` 方法也出现菱形问题怎么办？**  
A：如果一个类实现的两个接口有同名 `default` 方法，编译器会强制要求类自己重写该方法，明确指定用哪个版本。

**Q：抽象类一定要有抽象方法吗？**  
A：不一定。没有抽象方法的抽象类是合法的，只是不能被实例化。但这种情况通常意味着设计有问题，应该重新考虑是否真的需要抽象类。

**Q：`@Override` 注解不写会怎样？**  
A：不写也能运行，但失去了编译器检查。如果方法名拼错或参数不对，没有 `@Override` 时编译器以为你在定义新方法，不会报错，运行时行为出乎意料。强烈建议始终写。

**Q：接口可以继承接口吗？**  
A：可以，而且可以继承多个接口：

```java
interface FlySwimmable extends Flyable, Swimmable {
    void migrate();  // 迁徙
}
```
