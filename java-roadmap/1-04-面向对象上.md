## 1. 什么是面向对象

**面向对象编程（OOP，Object-Oriented Programming）** 是一种把程序看作"对象集合"的编程思想。每个对象有自己的数据（属性）和行为（方法），对象之间通过互相调用来协作完成任务。

### 1.1 面向过程 vs 面向对象

用"开车去上班"举例：

**面向过程**：按步骤描述——开门 → 坐进去 → 系安全带 → 启动 → 开车 → 停车 → 下车

**面向对象**：描述参与者——

- `人` 对象：有姓名、会开车
- `车` 对象：有品牌、能启动、能停止
- `人` 调用 `车` 的方法来完成出行

面向对象的优势在于：当需求变化时（比如换一辆车），只需要修改 `车` 这个类，不用重写整个流程。

### 1.2 OOP 三大特性

- **封装**：隐藏内部细节，只暴露必要的接口（本节重点）
- **继承**：子类复用父类的属性和方法（1-05 讲）
- **多态**：同一个方法在不同对象上有不同表现（1-05 讲）

## 2. 类与对象

### 2.1 概念

- **类（Class）**：模板/蓝图，描述一类事物的共同属性和行为
- **对象（Object）**：类的具体实例，是真实存在的个体

类和对象的关系：类是"人类"，对象是具体的"张三"、"李四"。

### 2.2 定义类

```java
// 定义一个 Person 类
public class Person {
    // 属性（成员变量）
    String name;
    int age;
    String city;

    // 行为（成员方法）
    void introduce() {
        System.out.println("我叫 " + name + "，今年 " + age + " 岁，来自 " + city);
    }

    void birthday() {
        age++;
        System.out.println(name + " 过生日了，现在 " + age + " 岁");
    }
}
```

### 2.3 创建对象

```java
public class Main {
    public static void main(String[] args) {
        // 用 new 关键字创建对象
        Person p1 = new Person();

        // 给属性赋值
        p1.name = "张三";
        p1.age = 25;
        p1.city = "北京";

        // 调用方法
        p1.introduce();   // 我叫 张三，今年 25 岁，来自 北京
        p1.birthday();    // 张三 过生日了，现在 26 岁

        // 可以创建多个对象，互相独立
        Person p2 = new Person();
        p2.name = "李四";
        p2.age = 30;
        p2.city = "上海";
        p2.introduce();   // 我叫 李四，今年 30 岁，来自 上海
    }
}
```

> **每个对象都有自己独立的属性**，修改 `p1.age` 不会影响 `p2.age`。

### 2.4 对象在内存中的样子

```
栈内存                堆内存
--------          ----------------
p1  ──────────→  | name = "张三"  |
                 | age  = 25     |
                 | city = "北京"  |
                 ----------------

p2  ──────────→  | name = "李四"  |
                 | age  = 30     |
                 | city = "上海"  |
                 ----------------
```

变量 `p1`、`p2` 存在栈上，保存的是对象的内存地址（引用）。对象本身在堆上。这就是为什么 Java 里对象变量叫"引用类型"。

## 3. 成员变量与成员方法

### 3.1 成员变量

定义在类里、方法外的变量，每个对象都有一份：

```java
public class Student {
    String name;      // 默认值 null
    int age;          // 默认值 0
    double gpa;       // 默认值 0.0
    boolean enrolled; // 默认值 false
}
```

> 成员变量有默认值（数值类型为 0，boolean 为 false，引用类型为 null）。  
> 局部变量（方法内部）没有默认值，必须手动赋值才能使用。

### 3.2 成员方法

定义对象的行为，可以访问和修改成员变量：

```java
public class Circle {
    double radius;

    // 计算面积
    double getArea() {
        return Math.PI * radius * radius;
    }

    // 计算周长
    double getPerimeter() {
        return 2 * Math.PI * radius;
    }

    // 判断是否比另一个圆大
    boolean isBiggerThan(Circle other) {
        return this.radius > other.radius;
    }
}
```

### 3.3 方法重载（Overload）

同一个类里，方法名相同但参数不同，叫做方法重载：

```java
public class Calculator {

    // 两个整数相加
    int add(int a, int b) {
        return a + b;
    }

    // 三个整数相加
    int add(int a, int b, int c) {
        return a + b + c;
    }

    // 两个小数相加
    double add(double a, double b) {
        return a + b;
    }
}
```

```java
Calculator calc = new Calculator();
calc.add(1, 2);        // 调用第一个，返回 3
calc.add(1, 2, 3);     // 调用第二个，返回 6
calc.add(1.5, 2.5);    // 调用第三个，返回 4.0
```

> **重载的判断标准是参数列表**（参数个数或类型不同），和返回值类型无关。

## 4. 构造方法

### 4.1 什么是构造方法

构造方法（Constructor）是创建对象时自动调用的特殊方法，用于**初始化对象的属性**。

特点：

- 方法名和类名完全一致
- 没有返回值（连 `void` 都不写）
- 用 `new` 关键字调用

### 4.2 默认构造方法

如果你没有写任何构造方法，Java 会自动提供一个无参的默认构造方法：

```java
public class Person {
    String name;
    int age;
    // Java 自动生成：public Person() {}
}

Person p = new Person(); // 调用默认构造方法
```

### 4.3 自定义构造方法

```java
public class Person {
    String name;
    int age;
    String city;

    // 无参构造方法
    public Person() {
        this.name = "未知";
        this.age = 0;
    }

    // 有参构造方法
    public Person(String name, int age) {
        this.name = name;
        this.age = age;
    }

    // 全参构造方法
    public Person(String name, int age, String city) {
        this.name = name;
        this.age = age;
        this.city = city;
    }
}
```

```java
Person p1 = new Person();                    // 调用无参构造
Person p2 = new Person("张三", 25);          // 调用两参构造
Person p3 = new Person("李四", 30, "上海");  // 调用全参构造

System.out.println(p1.name);  // 未知
System.out.println(p2.name);  // 张三
System.out.println(p3.city);  // 上海
```

> ⚠️ **注意**：一旦你定义了有参构造方法，Java 就不再自动提供默认无参构造方法。如果还需要无参构造，必须手动写。

### 4.4 构造方法互相调用：this()

```java
public class Person {
    String name;
    int age;
    String city;

    public Person(String name) {
        this(name, 0, "未知");  // 调用三参构造
    }

    public Person(String name, int age, String city) {
        this.name = name;
        this.age = age;
        this.city = city;
    }
}
```

> `this()` 必须是构造方法的第一行。

## 5. this 关键字

`this` 代表**当前对象本身**，有三种常见用途：

### 5.1 区分成员变量和局部变量

```java
public class Person {
    String name;  // 成员变量

    public Person(String name) {  // name 是局部变量（参数）
        // name = name;  ❌ 这样写是局部变量赋值给局部变量，没意义
        this.name = name;  // ✅ this.name 是成员变量
    }
}
```

### 5.2 在方法中返回当前对象（链式调用）

```java
public class Builder {
    String name;
    int age;

    public Builder setName(String name) {
        this.name = name;
        return this;  // 返回当前对象
    }

    public Builder setAge(int age) {
        this.age = age;
        return this;
    }
}

// 链式调用
Builder b = new Builder()
    .setName("张三")
    .setAge(25);
```

### 5.3 调用本类的其他构造方法

见上一节 `this()` 的用法。

## 6. 封装

### 6.1 为什么要封装

不封装的问题：

```java
public class BankAccount {
    double balance;  // 余额直接暴露
}

BankAccount account = new BankAccount();
account.balance = -99999;  // 可以随意设置负数余额！
```

余额被随意篡改，这显然不合理。封装就是为了解决这个问题。

### 6.2 封装的实现

**原则：属性私有（`private`），方法公开（`public`）**

```java
public class BankAccount {
    private double balance;  // 私有，外部无法直接访问
    private String owner;

    public BankAccount(String owner, double initialBalance) {
        this.owner = owner;
        if (initialBalance >= 0) {
            this.balance = initialBalance;
        }
    }

    // getter：获取余额
    public double getBalance() {
        return balance;
    }

    // 存款
    public void deposit(double amount) {
        if (amount <= 0) {
            System.out.println("存款金额必须大于 0");
            return;
        }
        balance += amount;
        System.out.println("存入 " + amount + " 元，余额：" + balance);
    }

    // 取款
    public void withdraw(double amount) {
        if (amount <= 0) {
            System.out.println("取款金额必须大于 0");
            return;
        }
        if (amount > balance) {
            System.out.println("余额不足");
            return;
        }
        balance -= amount;
        System.out.println("取出 " + amount + " 元，余额：" + balance);
    }
}
```

```java
BankAccount account = new BankAccount("张三", 1000);

// account.balance = -99999;  ❌ 编译报错，private 无法直接访问

account.deposit(500);    // 存入 500 元，余额：1500.0
account.withdraw(2000);  // 余额不足
account.withdraw(300);   // 取出 300 元，余额：1200.0
System.out.println(account.getBalance());  // 1200.0
```

### 6.3 访问修饰符

| 修饰符      | 本类 | 同包 | 子类 | 其他 |
| ----------- | ---- | ---- | ---- | ---- |
| `private`   | ✅   | ❌   | ❌   | ❌   |
| （默认）    | ✅   | ✅   | ❌   | ❌   |
| `protected` | ✅   | ✅   | ✅   | ❌   |
| `public`    | ✅   | ✅   | ✅   | ✅   |

**实际开发规范：**

- 成员变量一律 `private`
- 对外提供的方法用 `public`
- 类内部的辅助方法用 `private`

### 6.4 getter 和 setter

标准的封装写法是为每个私有属性提供 getter（读）和 setter（写）方法：

```java
public class Person {
    private String name;
    private int age;

    // getter
    public String getName() { return name; }
    public int getAge() { return age; }

    // setter（可以在这里加校验逻辑）
    public void setName(String name) {
        if (name == null || name.isBlank()) {
            throw new IllegalArgumentException("姓名不能为空");
        }
        this.name = name;
    }

    public void setAge(int age) {
        if (age < 0 || age > 150) {
            throw new IllegalArgumentException("年龄不合法：" + age);
        }
        this.age = age;
    }
}
```

> **IDEA 快捷生成**：在类里右键 → Generate → Getter and Setter，自动生成所有 getter/setter，不用手写。

## 7. static 关键字

### 7.1 静态变量

`static` 修饰的变量属于**类本身**，所有对象共享同一份：

```java
public class Student {
    private String name;
    private int age;
    private static int count = 0;  // 静态变量，记录学生总数

    public Student(String name, int age) {
        this.name = name;
        this.age = age;
        count++;  // 每创建一个对象，总数加 1
    }

    public static int getCount() {
        return count;
    }
}
```

```java
System.out.println(Student.getCount());  // 0

Student s1 = new Student("张三", 20);
Student s2 = new Student("李四", 21);
Student s3 = new Student("王五", 22);

System.out.println(Student.getCount());  // 3
```

### 7.2 静态方法

`static` 修饰的方法属于类，**不需要创建对象就能调用**：

```java
public class MathUtils {

    // 静态方法：工具类的常见写法
    public static int max(int a, int b) {
        return a > b ? a : b;
    }

    public static boolean isEven(int n) {
        return n % 2 == 0;
    }
}
```

```java
// 直接用类名调用，不需要 new
int result = MathUtils.max(10, 20);      // 20
boolean even = MathUtils.isEven(4);     // true
```

> 你前面一直用的 `Math.PI`、`Arrays.sort()`、`Integer.parseInt()` 都是静态成员，这就是为什么不需要 `new` 就能用。

### 7.3 静态方法的限制

```java
public class Demo {
    private String name = "张三";
    private static int count = 0;

    public static void test() {
        System.out.println(count);  // ✅ 可以访问静态变量
        System.out.println(name);   // ❌ 报错！静态方法不能访问非静态成员
        // 因为静态方法调用时可能还没有对象存在，name 根本不存在
    }
}
```

## 8. 和 JavaScript 的对比

JS 从 ES6 开始也有 `class` 语法，和 Java 的类很像，但本质不同：

```javascript
// JavaScript class
class Person {
  constructor(name, age) {
    this.name = name;
    this.age = age;
  }

  introduce() {
    console.log(`我叫 ${this.name}，${this.age} 岁`);
  }
}

const p = new Person("张三", 25);
p.introduce();
p.name = "李四"; // ✅ JS 可以随意修改属性，没有 private
```

```java
// Java class
public class Person {
    private String name;  // private，外部不能直接改
    private int age;

    public Person(String name, int age) {
        this.name = name;
        this.age = age;
    }

    public void introduce() {
        System.out.println("我叫 " + name + "，" + age + " 岁");
    }
}

Person p = new Person("张三", 25);
p.introduce();
p.name = "李四";  // ❌ 编译报错，private 不能访问
```

| 特性     | Java                         | JavaScript                                |
| -------- | ---------------------------- | ----------------------------------------- |
| 私有属性 | `private` 关键字，编译器强制 | `#name` 私有字段（ES2022+）或约定 `_name` |
| 构造方法 | 方法名和类名相同             | 固定叫 `constructor`                      |
| 静态成员 | `static` 关键字              | `static` 关键字（ES6+）                   |
| 类型检查 | 编译时，传错类型直接报错     | 运行时才发现                              |
| 本质     | 真正的类                     | 基于原型链的语法糖                        |

## 常见问题

**Q：什么时候用静态方法，什么时候用实例方法？**  
A：工具类方法（不依赖对象状态的纯计算）用静态方法，如 `Math.max()`。依赖对象属性的行为用实例方法。

**Q：构造方法可以有返回值吗？**  
A：不能有返回值声明（连 `void` 都不行）。`new` 表达式本身会返回新创建的对象引用。

**Q：一个 .java 文件里可以定义多个类吗？**  
A：可以定义多个类，但只能有一个 `public` 类，且 `public` 类的名字必须和文件名一致。实际开发中一般一个文件一个类。

**Q：getter/setter 有必要每个属性都写吗？**  
A：不一定。只读属性只提供 getter，不提供 setter。有些属性完全内部使用，getter/setter 都不需要。根据实际需要决定。

**Q：`private` 修饰的属性，同一个类的不同对象之间能互相访问吗？**  
A：可以。`private` 是类级别的限制，同一个类的方法可以访问任意该类对象的私有成员。比如 `isBiggerThan(Circle other)` 里可以直接访问 `other.radius`，即使它是 `private` 的。
