## 1. Math 类

`Math` 是工具类，所有方法都是静态的，直接用类名调用，不需要 `new`。

### 1.1 常用常量

```java
Math.PI;   // 3.141592653589793
Math.E;    // 2.718281828459045（自然对数的底）
```

### 1.2 基本运算

```java
// 绝对值
Math.abs(-10);      // 10
Math.abs(-3.14);    // 3.14

// 最大值 / 最小值
Math.max(10, 20);   // 20
Math.min(10, 20);   // 10

// 幂运算
Math.pow(2, 10);    // 1024.0（2 的 10 次方）
Math.pow(3, 3);     // 27.0

// 平方根
Math.sqrt(16);      // 4.0
Math.sqrt(2);       // 1.4142135623730951

// 取整
Math.ceil(3.1);     // 4.0（向上取整）
Math.floor(3.9);    // 3.0（向下取整）
Math.round(3.5);    // 4（四舍五入，返回 long）
Math.round(3.4);    // 3

// 随机数（0.0 ≤ x < 1.0）
Math.random();      // 如 0.7234...
```

### 1.3 对数与三角函数

```java
Math.log(Math.E);   // 1.0（自然对数）
Math.log10(100);    // 2.0（以 10 为底的对数）

Math.sin(Math.PI / 2);  // 1.0
Math.cos(0);            // 1.0
Math.tan(Math.PI / 4);  // 1.0（约等于）
```

### 1.4 实用示例

```java
// 生成 [min, max] 范围内的随机整数
int min = 1, max = 100;
int randomNum = (int) (Math.random() * (max - min + 1)) + min;

// 保留两位小数（用 Math.round）
double price = 3.14159;
double rounded = Math.round(price * 100) / 100.0;
System.out.println(rounded);  // 3.14
```

## 2. 包装类

### 2.1 什么是包装类

Java 的 8 种基本类型都有对应的**包装类（Wrapper Class）**，把基本类型"包装"成对象：

| 基本类型  | 包装类      |
| --------- | ----------- |
| `byte`    | `Byte`      |
| `short`   | `Short`     |
| `int`     | `Integer`   |
| `long`    | `Long`      |
| `float`   | `Float`     |
| `double`  | `Double`    |
| `char`    | `Character` |
| `boolean` | `Boolean`   |

**为什么需要包装类？**

- 集合（`List`、`Map` 等）只能存对象，不能存基本类型
- 包装类提供了很多实用的工具方法
- 泛型不支持基本类型

### 2.2 自动装箱与拆箱

JDK 5+ 开始，基本类型和包装类之间可以**自动互转**：

```java
// 装箱：基本类型 → 包装类（自动）
Integer a = 100;          // 等同于 Integer a = Integer.valueOf(100);
Double d = 3.14;          // 等同于 Double.valueOf(3.14)

// 拆箱：包装类 → 基本类型（自动）
int x = a;                // 等同于 a.intValue()
double y = d;             // 等同于 d.doubleValue()

// 混合运算时自动拆箱
Integer m = 10;
Integer n = 20;
int sum = m + n;          // 自动拆箱后相加
```

> ⚠️ **装箱陷阱：Integer 缓存**
>
> ```java
> Integer a = 127;
> Integer b = 127;
> System.out.println(a == b);   // true（缓存范围 -128~127）
>
> Integer c = 128;
> Integer d = 128;
> System.out.println(c == d);   // false！超出缓存，是不同对象
> System.out.println(c.equals(d)); // true（比较值用 equals）
> ```
>
> **记住：包装类比较永远用 `equals()`，不用 `==`。**

### 2.3 Integer 常用方法

```java
// 字符串转数字
int a = Integer.parseInt("123");        // 123
int b = Integer.parseInt("FF", 16);     // 255（16进制转10进制）

// 数字转字符串
String s1 = Integer.toString(42);       // "42"
String s2 = Integer.toBinaryString(10); // "1010"（转二进制）
String s3 = Integer.toHexString(255);   // "ff"（转十六进制）

// 大小限制
System.out.println(Integer.MAX_VALUE);  // 2147483647
System.out.println(Integer.MIN_VALUE);  // -2147483648

// 比较
Integer.compare(10, 20);  // 负数（10 < 20）
Integer.max(10, 20);      // 20
Integer.min(10, 20);      // 10
```

### 2.4 Character 常用方法

```java
char c = 'A';

Character.isLetter(c);      // true（是否是字母）
Character.isDigit('5');     // true（是否是数字）
Character.isWhitespace(' ');// true（是否是空白字符）
Character.isUpperCase(c);   // true（是否大写）
Character.isLowerCase(c);   // false
Character.toUpperCase('a'); // 'A'
Character.toLowerCase('A'); // 'a'
```

## 3. 日期时间（旧 API）

> **了解即可**，实际开发用新 API（第 4 节）。但旧项目里会看到，需要认识。

### 3.1 Date

```java
import java.util.Date;

Date now = new Date();
System.out.println(now);           // Thu Jun 19 10:30:00 CST 2026
System.out.println(now.getTime()); // 时间戳（毫秒）
```

### 3.2 SimpleDateFormat

```java
import java.text.SimpleDateFormat;
import java.util.Date;

SimpleDateFormat sdf = new SimpleDateFormat("yyyy-MM-dd HH:mm:ss");

// 日期 → 字符串
String formatted = sdf.format(new Date());
System.out.println(formatted);  // 2026-06-19 10:30:00

// 字符串 → 日期
Date parsed = sdf.parse("2026-01-01 00:00:00");
```

**格式符号：**

| 符号   | 含义         | 示例 |
| ------ | ------------ | ---- |
| `yyyy` | 年（4位）    | 2026 |
| `MM`   | 月（2位）    | 06   |
| `dd`   | 日（2位）    | 19   |
| `HH`   | 时（24小时） | 10   |
| `mm`   | 分           | 30   |
| `ss`   | 秒           | 00   |
| `SSS`  | 毫秒         | 123  |

## 4. 日期时间（新 API：java.time）

JDK 8 引入的新日期时间 API，设计更合理，**不可变、线程安全**，是现在的推荐写法。

### 4.1 核心类

| 类                  | 用途                       |
| ------------------- | -------------------------- |
| `LocalDate`         | 只有日期（年月日），无时间 |
| `LocalTime`         | 只有时间（时分秒），无日期 |
| `LocalDateTime`     | 日期 + 时间                |
| `ZonedDateTime`     | 带时区的日期时间           |
| `Instant`           | 时间戳（精确到纳秒）       |
| `Duration`          | 时间段（小时、分钟、秒）   |
| `Period`            | 日期段（年、月、日）       |
| `DateTimeFormatter` | 日期时间格式化             |

### 4.2 LocalDate

```java
import java.time.LocalDate;

// 获取今天
LocalDate today = LocalDate.now();
System.out.println(today);          // 2026-06-19

// 指定日期
LocalDate birthday = LocalDate.of(2000, 1, 15);
System.out.println(birthday);       // 2000-01-15

// 获取各部分
System.out.println(today.getYear());        // 2026
System.out.println(today.getMonthValue());  // 6
System.out.println(today.getDayOfMonth());  // 19
System.out.println(today.getDayOfWeek());   // FRIDAY

// 日期计算（返回新对象，不修改原对象）
LocalDate nextWeek = today.plusDays(7);
LocalDate lastMonth = today.minusMonths(1);
LocalDate nextYear = today.plusYears(1);

// 比较
today.isBefore(nextWeek);   // true
today.isAfter(lastMonth);   // true
today.isEqual(today);       // true
```

### 4.3 LocalTime

```java
import java.time.LocalTime;

LocalTime now = LocalTime.now();
System.out.println(now);             // 10:30:45.123

LocalTime time = LocalTime.of(9, 30, 0);
System.out.println(time);            // 09:30

System.out.println(now.getHour());   // 10
System.out.println(now.getMinute()); // 30

LocalTime later = time.plusHours(2).plusMinutes(30);
System.out.println(later);           // 12:00
```

### 4.4 LocalDateTime

```java
import java.time.LocalDateTime;

LocalDateTime now = LocalDateTime.now();
System.out.println(now);  // 2026-06-19T10:30:45.123

// 组合 LocalDate 和 LocalTime
LocalDate date = LocalDate.of(2026, 6, 19);
LocalTime time = LocalTime.of(10, 30);
LocalDateTime dt = LocalDateTime.of(date, time);

// 各种操作
dt.plusDays(1).minusHours(2);

// LocalDateTime → LocalDate / LocalTime
dt.toLocalDate();
dt.toLocalTime();
```

### 4.5 DateTimeFormatter（格式化）

```java
import java.time.LocalDateTime;
import java.time.format.DateTimeFormatter;

LocalDateTime now = LocalDateTime.now();

// 预定义格式
System.out.println(now.format(DateTimeFormatter.ISO_LOCAL_DATE));
// 2026-06-19

// 自定义格式
DateTimeFormatter formatter = DateTimeFormatter.ofPattern("yyyy年MM月dd日 HH:mm:ss");
String formatted = now.format(formatter);
System.out.println(formatted);  // 2026年06月19日 10:30:45

// 字符串 → LocalDateTime
String dateStr = "2026-01-01 00:00:00";
DateTimeFormatter parser = DateTimeFormatter.ofPattern("yyyy-MM-dd HH:mm:ss");
LocalDateTime parsed = LocalDateTime.parse(dateStr, parser);
```

### 4.6 Duration 与 Period（时间差计算）

```java
import java.time.*;

// Period：计算日期差（年、月、日）
LocalDate start = LocalDate.of(2000, 1, 15);
LocalDate end = LocalDate.now();
Period period = Period.between(start, end);
System.out.printf("年龄：%d 岁 %d 个月 %d 天%n",
    period.getYears(), period.getMonths(), period.getDays());

// Duration：计算时间差（小时、分钟、秒）
LocalDateTime t1 = LocalDateTime.of(2026, 6, 19, 9, 0);
LocalDateTime t2 = LocalDateTime.of(2026, 6, 19, 17, 30);
Duration duration = Duration.between(t1, t2);
System.out.println("工作时长：" + duration.toHours() + " 小时");
// 工作时长：8 小时
```

## 5. Random 类

比 `Math.random()` 更灵活的随机数工具：

```java
import java.util.Random;

Random random = new Random();

// 随机整数（范围 [0, bound)）
int r1 = random.nextInt(10);     // 0 ~ 9
int r2 = random.nextInt(100);    // 0 ~ 99

// 指定范围 [min, max]
int min = 1, max = 6;
int dice = random.nextInt(max - min + 1) + min;  // 骰子：1 ~ 6

// 随机小数 [0.0, 1.0)
double d = random.nextDouble();

// 随机布尔值
boolean b = random.nextBoolean();

// JDK 17+ 更简洁的方式
int r3 = random.nextInt(1, 7);   // 直接指定 [1, 7)，即 1 ~ 6
```

### 固定种子（可复现的随机数）

```java
// 相同种子产生相同的随机序列，用于测试
Random r = new Random(42);
System.out.println(r.nextInt(100));  // 每次运行结果相同
```

## 6. Scanner 类

从控制台读取用户输入：

```java
import java.util.Scanner;

Scanner scanner = new Scanner(System.in);

System.out.print("请输入姓名：");
String name = scanner.nextLine();   // 读取一整行

System.out.print("请输入年龄：");
int age = scanner.nextInt();        // 读取整数

System.out.print("请输入身高：");
double height = scanner.nextDouble(); // 读取小数

System.out.println("姓名：" + name + "，年龄：" + age + "，身高：" + height);

// 用完要关闭
scanner.close();
```

> ⚠️ **常见陷阱**：`nextInt()` 读取数字后，换行符还留在缓冲区，紧接着调用 `nextLine()` 会读到空字符串。解决方法：在 `nextInt()` 后加一行 `scanner.nextLine()` 消耗掉多余的换行符。
>
> ```java
> int age = scanner.nextInt();
> scanner.nextLine();  // 消耗换行符
> String name = scanner.nextLine();  // 这样才能正常读取
> ```

### Scanner 读取文件（扩展了解）

```java
import java.io.File;
import java.util.Scanner;

Scanner fileScanner = new Scanner(new File("data.txt"));
while (fileScanner.hasNextLine()) {
    String line = fileScanner.nextLine();
    System.out.println(line);
}
fileScanner.close();
```

## 7. 和 JavaScript 的对比

### Math 对比

| 操作     | Java              | JavaScript                     |
| -------- | ----------------- | ------------------------------ |
| 绝对值   | `Math.abs(-5)`    | `Math.abs(-5)`                 |
| 最大值   | `Math.max(a, b)`  | `Math.max(a, b)`               |
| 幂运算   | `Math.pow(2, 10)` | `Math.pow(2, 10)` 或 `2 ** 10` |
| 平方根   | `Math.sqrt(16)`   | `Math.sqrt(16)`                |
| 向上取整 | `Math.ceil(3.1)`  | `Math.ceil(3.1)`               |
| 向下取整 | `Math.floor(3.9)` | `Math.floor(3.9)`              |
| 四舍五入 | `Math.round(3.5)` | `Math.round(3.5)`              |
| 随机数   | `Math.random()`   | `Math.random()`                |

Math 方法两者基本一致，差异不大。

### 日期时间对比

| 操作         | Java（新 API）               | JavaScript                      |
| ------------ | ---------------------------- | ------------------------------- |
| 获取当前时间 | `LocalDateTime.now()`        | `new Date()`                    |
| 格式化       | `DateTimeFormatter`          | `toLocaleDateString()` 或 dayjs |
| 时间计算     | `plusDays()`、`minusHours()` | 手动加减毫秒 或 dayjs           |
| 不可变性     | ✅ 所有操作返回新对象        | ❌ Date 是可变的                |
| 线程安全     | ✅                           | -                               |

Java 的新日期 API 设计比 JS 原生 `Date` 好得多——不可变、语义清晰、功能完善。JS 开发者通常用 dayjs / date-fns 解决 Date 的问题，而 Java 8+ 内置就解决了。

### 用户输入

JS 在浏览器里用 `prompt()`，Node.js 里用 `readline`。Java 用 `Scanner`，概念类似但更繁琐一些。实际后端开发中几乎用不到 `Scanner`，主要用在学习阶段练习控制台交互。

## 常见问题

**Q：`Math.round()` 返回的是 `long` 还是 `int`？**  
A：参数是 `float` 时返回 `int`，参数是 `double` 时返回 `long`。注意接收时类型要匹配。

**Q：`LocalDate`、`LocalDateTime` 有没有时区问题？**  
A：`LocalDate` 和 `LocalDateTime` 不含时区信息，适合本地业务（如生日、会议时间）。跨时区场景（如国际化应用、存储 UTC 时间）用 `ZonedDateTime` 或 `Instant`。

**Q：旧项目里大量用 `Date` 和 `Calendar`，需要学吗？**  
A：`Calendar` 可以不学，太繁琐。`Date` 和 `SimpleDateFormat` 认识就行，能读懂老代码即可。新项目统一用 `java.time`。

**Q：`Random` 和 `Math.random()` 有什么区别？**  
A：`Math.random()` 底层也是用 `Random` 实现的，只是简单返回 `[0.0, 1.0)` 的 double。`Random` 类功能更丰富，可以生成不同类型的随机数、设置种子。多线程环境下推荐用 `ThreadLocalRandom`。

**Q：`Scanner` 用完为什么要 `close()`？**  
A：`Scanner` 包装了底层的输入流，不关闭会造成资源泄漏。实际上可以用 `try-with-resources` 自动关闭：

```java
try (Scanner scanner = new Scanner(System.in)) {
    String input = scanner.nextLine();
}
// 自动调用 close()
```

`try-with-resources` 在 1-09 异常处理那节会详细讲。
