# Java 后端全栈学习路线

**一套面向零基础学习者的 Java 后端系统学习路线**

> 本路线不限制学习天数，按模块推进，学扎实再进入下一阶段。每天建议投入 2-4 小时。

## 阶段一：Java 语言基础

> 目标：能用 Java 独立编写业务逻辑，理解面向对象设计思想，掌握常用 API 与 Java 8+ 新特性。
> 预计耗时：20-25 个学习单元

| 模块 | 主题                    | 关键词                                        |
| ---- | ----------------------- | --------------------------------------------- |
| 1-01 | 环境搭建与初印象        | JDK 安装、IDEA、Hello World、编译运行         |
| 1-02 | 基本语法                | 数据类型、变量、运算符、流程控制              |
| 1-03 | 数组与字符串            | 数组操作、String/StringBuilder、常用方法      |
| 1-04 | 面向对象（上）          | 类与对象、构造方法、封装、this 关键字         |
| 1-05 | 面向对象（下）          | 继承、多态、抽象类、接口                      |
| 1-06 | 常用类库                | Math、Date、LocalDateTime、包装类             |
| 1-07 | 集合框架（上）          | List、Set、Map 基本使用                       |
| 1-08 | 集合框架（下）          | ArrayList vs LinkedList、HashMap 原理         |
| 1-09 | 异常处理                | try-catch-finally、自定义异常、异常链         |
| 1-10 | 🏆 里程碑：命令行小项目 | 学生管理系统（纯 Java，无框架）               |
| 1-11 | IO 流基础               | File、InputStream/OutputStream、Reader/Writer |
| 1-12 | 泛型与注解              | 泛型类/方法/通配符、自定义注解、反射基础      |
| 1-13 | Java 8 新特性（上）     | Lambda 表达式、函数式接口、方法引用           |
| 1-14 | Java 8 新特性（下）     | Stream API、Optional、日期时间 API            |
| 1-15 | 多线程基础              | Thread、Runnable、synchronized、线程池简介    |
| 1-16 | 🎯 阶段一总结与测验     | 知识回顾、编码测验、常见面试题初探            |

## 阶段二：后端框架与数据库

> 目标：掌握 Spring Boot 核心机制，能独立搭建 RESTful API，并接入 MySQL 数据库完成 CRUD 开发。
> 预计耗时：18-22 个学习单元

| 模块 | 主题                       | 关键词                                     |
| ---- | -------------------------- | ------------------------------------------ |
| 2-01 | Maven 与项目结构           | Maven 依赖管理、pom.xml、生命周期          |
| 2-02 | Spring Boot 入门           | 自动装配、starter、application.yml         |
| 2-03 | IoC 与依赖注入             | Bean、@Component、@Autowired、容器原理     |
| 2-04 | Controller 与路由          | @RestController、@RequestMapping、参数绑定 |
| 2-05 | Service 与分层架构         | 三层架构、业务逻辑分离、接口设计           |
| 2-06 | 请求验证与异常处理         | @Valid、BindingResult、全局异常处理器      |
| 2-07 | 🏆 里程碑：内存版 TODO API | 无数据库的完整 CRUD，Postman 联调          |
| 2-08 | MySQL 入门                 | Docker 安装、SQL 基础、DDL/DML             |
| 2-09 | SQL 进阶                   | JOIN、子查询、聚合函数、索引基础           |
| 2-10 | 数据库建模                 | 范式、ER 图、一对多/多对多关系设计         |
| 2-11 | MyBatis Plus 入门          | 基本 CRUD、BaseMapper、条件构造器          |
| 2-12 | MyBatis Plus 进阶          | 分页、逻辑删除、乐观锁、自动填充           |
| 2-13 | Spring Boot + MyBatis 整合 | 数据源配置、事务管理、@Transactional       |
| 2-14 | RESTful API 设计原则       | 资源命名、HTTP 动词、版本化、状态码规范    |
| 2-15 | API 文档与测试             | Swagger/Knife4j、接口文档生成              |
| 2-16 | 🏆 里程碑：博客系统 v1.0   | 文章/分类/标签 CRUD，完整 REST API         |

> 目标：实现生产级认证授权体系，集成 Redis 缓存，构建安全加固版后端服务。

| 模块 | 主题                     | 关键词                                     |
| ---- | ------------------------ | ------------------------------------------ |
| 3-01 | 认证基础                 | Session vs JWT、有状态/无状态、Token 结构  |
| 3-02 | JWT 认证实战             | BCrypt 加密、双 Token、注册登录接口        |
| 3-03 | Spring Security 入门     | 过滤器链、SecurityConfig、自定义认证       |
| 3-04 | RBAC 权限模型            | 角色权限设计、方法级权限、资源级控制       |
| 3-05 | OAuth 2.0 与第三方登录   | 授权码模式、GitHub/微信登录接入            |
| 3-06 | Web 安全防护             | XSS、CSRF、SQL 注入防护、HTTPS 配置        |
| 3-07 | Redis 基础               | 数据结构、Spring Data Redis、序列化        |
| 3-08 | Redis 缓存策略           | Cache-Aside、缓存穿透/击穿/雪崩            |
| 3-09 | Redis 进阶应用           | 排行榜、分布式锁、Session 共享             |
| 3-10 | 消息队列基础             | RabbitMQ 核心概念、Spring AMQP、异步解耦   |
| 3-11 | 文件上传与存储           | Multipart、本地存储、对象存储（OSS/MinIO） |
| 3-12 | 🏆 里程碑：博客系统 v2.0 | 接入认证授权、Redis 缓存、文件上传         |

## 学习建议

1. **按顺序推进** — 每个模块建立在前一个基础之上，不建议跳跃
2. **动手编码** — 每个模块都要完成对应的练习，光看不练等于没学
3. **里程碑项目优先** — 遇到里程碑模块时，务必完成可运行的代码再继续
4. **结合前端视角** — 有 Vue/JS 基础的话，可以主动类比（Spring IoC ↔ NestJS DI、MyBatis ↔ Sequelize、Stream API ↔ JS 数组方法）
5. **记录学习笔记** — 用自己的话总结，比单纯看代码记得更牢
