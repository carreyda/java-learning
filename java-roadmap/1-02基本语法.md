## 1. 注释

注释不会被编译，只用来说明代码。

```java
// 单行注释

/*
 * 多行注释
 * 可以写多行
 */

/**
 * 文档注释（Javadoc）
 * 用于生成 API 文档，一般写在类或方法上面
 */
```

> 养成写注释的习惯，大厂代码规范里注释是强制要求的。

## 2. 数据类型

Java 是**强类型语言**，每个变量都必须有明确的类型，且类型一旦声明不能改变。

### 2.1 基本数据类型（8 种）

| 类型      | 大小   | 范围 / 说明              | 默认值     |
| --------- | ------ | ------------------------ | ---------- |
| `byte`    | 1 字节 | -128 ~ 127               | 0          |
| `short`   | 2 字节 | -32768 ~ 32767           | 0          |
| `int`     | 4 字节 | 约 -21 亿 ~ 21 亿        | 0          |
| `long`    | 8 字节 | 极大整数                 | 0L         |
| `float`   | 4 字节 | 单精度小数               | 0.0f       |
| `double`  | 8 字节 | 双精度小数（更精确）     | 0.0        |
| `char`    | 2 字节 | 单个字符，用单引号 `'A'` | `'\u0000'` |
| `boolean` | -      | `true` / `false`         | `false`    |

**实际开发中常用的：**

- 整数用 `int`，超大整数用 `long`
- 小数用 `double`，涉及金额用 `BigDecimal`（不是基本类型）
- `byte` / `short` / `float` 较少直接使用

### 2.2 引用数据类型

除了 8 种基本类型，其他都是引用类型，最常见的是 `String`（字符串）。

```java
String name = "张三";       // 字符串用双引号
char gender = '男';         // 单个字符用单引号
```

> **基本类型 vs 引用类型的本质区别：**  
> 基本类型变量存的是**值本身**，引用类型变量存的是**对象的内存地址**（引用）。  
> 这和 JS 里的原始类型 vs 引用类型概念一样。

## 3. 变量与常量

### 3.1 变量声明

```java
// 格式：数据类型 变量名 = 初始值;
int age = 25;
double salary = 15000.5;
String city = "北京";
boolean isStudent = false;

// 也可以先声明再赋值
int score;
score = 90;

// 同类型可以一行声明多个（不推荐，可读性差）
int a = 1, b = 2, c = 3;
```

**变量命名规则：**

- 只能包含字母、数字、`_`、`$`，不能以数字开头
- 区分大小写：`name` 和 `Name` 是两个不同变量
- 不能使用关键字（`int`、`class`、`for` 等）
- 命名规范：小驼峰 `userName`，见名知意

### 3.2 常量

用 `final` 修饰，赋值后不可修改，命名全大写加下划线。

```java
final double PI = 3.14159;
final int MAX_SIZE = 100;

PI = 3.14; // ❌ 编译报错：无法修改 final 变量
```

### 3.3 var 关键字（JDK 10+）

类似 JS 的 `let`，编译器自动推断类型，但**只能用于局部变量**：

```java
var name = "张三";    // 推断为 String
var age = 25;         // 推断为 int
var list = new ArrayList<String>(); // 推断为 ArrayList<String>
```

> 注意：Java 的 `var` 只是省略显式类型声明，类型在编译时就确定了，和 JS 的动态类型完全不同。

## 4. 类型转换

### 4.1 自动类型转换（小转大，安全）

```
byte → short → int → long → float → double
```

```java
int a = 100;
long b = a;      // ✅ int 自动转 long
double c = a;    // ✅ int 自动转 double
```

### 4.2 强制类型转换（大转小，可能丢失精度）

```java
double d = 3.99;
int i = (int) d;  // i = 3，直接截断小数部分，不是四舍五入！

long big = 1000000000000L;
int small = (int) big; // 可能溢出，结果不可预期
```

### 4.3 字符串与数字互转

```java
// 字符串 → 数字
int num = Integer.parseInt("123");
double price = Double.parseDouble("99.9");

// 数字 → 字符串
String s1 = String.valueOf(123);
String s2 = 123 + "";   // 利用字符串拼接（不推荐）
```

## 5. 运算符

### 5.1 算术运算符

```java
int a = 10, b = 3;

System.out.println(a + b);  // 13
System.out.println(a - b);  // 7
System.out.println(a * b);  // 30
System.out.println(a / b);  // 3   ⚠️ 整数除法，结果是整数
System.out.println(a % b);  // 1   取余

// 要得到小数结果，需要至少一个 double
System.out.println((double) a / b);  // 3.3333...
System.out.println(10.0 / 3);        // 3.3333...
```

### 5.2 自增 / 自减

```java
int x = 5;
x++;   // 等同于 x = x + 1，x 变为 6
x--;   // 等同于 x = x - 1，x 变为 5

// 前缀 vs 后缀的区别
int a = 5;
int b = a++;  // b = 5，a = 6（先赋值再自增）
int c = ++a;  // c = 7，a = 7（先自增再赋值）
```

### 5.3 赋值运算符

```java
int n = 10;
n += 5;   // n = 15，等同于 n = n + 5
n -= 3;   // n = 12
n *= 2;   // n = 24
n /= 4;   // n = 6
n %= 4;   // n = 2
```

### 5.4 比较运算符

```java
int a = 5, b = 3;

a == b   // false，判断相等
a != b   // true，判断不等
a > b    // true
a < b    // false
a >= b   // true
a <= b   // false
```

> ⚠️ **字符串比较不能用 `==`**，要用 `.equals()`：
>
> ```java
> String s1 = new String("hello");
> String s2 = new String("hello");
> s1 == s2        // false！比较的是内存地址
> s1.equals(s2)   // true，比较的是内容
> ```

### 5.5 逻辑运算符

```java
boolean a = true, b = false;

a && b   // false，与（两个都为 true 才是 true）
a || b   // true，或（有一个为 true 就是 true）
!a       // false，非
```

**短路特性：**

- `&&`：左边为 `false`，右边不执行
- `||`：左边为 `true`，右边不执行

### 5.6 三元运算符

```java
// 格式：条件 ? 值1 : 值2
int a = 5, b = 3;
int max = a > b ? a : b;  // max = 5

String result = score >= 60 ? "及格" : "不及格";
```

## 6. 流程控制：条件判断

### 6.1 if / else if / else

```java
int score = 85;

if (score >= 90) {
    System.out.println("优秀");
} else if (score >= 75) {
    System.out.println("良好");
} else if (score >= 60) {
    System.out.println("及格");
} else {
    System.out.println("不及格");
}
// 输出：良好
```

### 6.2 switch

适合对同一个变量的多个固定值进行判断：

```java
int day = 3;

switch (day) {
    case 1:
        System.out.println("星期一");
        break;
    case 2:
        System.out.println("星期二");
        break;
    case 3:
        System.out.println("星期三");
        break;
    default:
        System.out.println("其他");
}
// 输出：星期三
```

> ⚠️ 每个 `case` 后面必须加 `break`，否则会"穿透"到下一个 case 继续执行。

**JDK 14+ 的新写法（更简洁，推荐）：**

```java
int day = 3;
String dayName = switch (day) {
    case 1 -> "星期一";
    case 2 -> "星期二";
    case 3 -> "星期三";
    default -> "其他";
};
System.out.println(dayName); // 星期三
```

箭头写法不会穿透，也不需要 `break`。

## 7. 流程控制：循环

### 7.1 for 循环

```java
// 格式：for (初始化; 条件; 更新) { ... }
for (int i = 0; i < 5; i++) {
    System.out.println("第 " + i + " 次");
}
// 输出：第 0 次 ~ 第 4 次

// 倒序
for (int i = 5; i > 0; i--) {
    System.out.println(i);
}
```

### 7.2 while 循环

条件为 true 就一直执行，适合不知道循环次数的场景：

```java
int n = 1;
while (n <= 5) {
    System.out.println(n);
    n++;
}
```

### 7.3 do-while 循环

先执行一次，再判断条件，至少执行一次：

```java
int n = 1;
do {
    System.out.println(n);
    n++;
} while (n <= 5);
```

### 7.4 break 和 continue

```java
// break：跳出整个循环
for (int i = 0; i < 10; i++) {
    if (i == 5) break;
    System.out.println(i); // 输出 0 1 2 3 4
}

// continue：跳过当次循环，继续下一次
for (int i = 0; i < 10; i++) {
    if (i % 2 == 0) continue;
    System.out.println(i); // 输出 1 3 5 7 9（跳过偶数）
}
```

### 7.5 嵌套循环示例：打印乘法表

```java
for (int i = 1; i <= 9; i++) {
    for (int j = 1; j <= i; j++) {
        System.out.print(j + "×" + i + "=" + (i * j) + "\t");
    }
    System.out.println(); // 换行
}
```

输出：

```
1×1=1
1×2=2	2×2=4
1×3=3	2×3=6	3×3=9
...
```

## 8. 和 JavaScript 的对比

| 特性          | Java                     | JavaScript             |
| ------------- | ------------------------ | ---------------------- |
| 类型声明      | 必须声明，`int age = 25` | 不需要，`let age = 25` |
| 类型检查      | 编译时，写错立刻报红     | 运行时，跑起来才知道   |
| 整数除法      | `10 / 3 = 3`（截断）     | `10 / 3 = 3.333...`    |
| 字符串比较    | 必须用 `.equals()`       | 直接用 `===`           |
| `switch` 穿透 | 需要手动 `break`         | 需要手动 `break`       |
| 自增自减      | `++` / `--` 同 JS        | 一样                   |
| 三元运算符    | `? :` 同 JS              | 一样                   |

**最容易踩的坑：**

```java
// 坑 1：整数除法
int result = 10 / 3;  // 结果是 3，不是 3.33

// 坑 2：字符串比较用了 ==
String a = new String("hello");
String b = new String("hello");
if (a == b) { ... }  // 永远不会进来！要用 a.equals(b)

// 坑 3：switch 忘写 break
switch (x) {
    case 1:
        System.out.println("one"); // 执行完会继续往下穿透！
    case 2:
        System.out.println("two");
}
```

## 常见问题

**Q：`int` 和 `Integer` 有什么区别？**  
A：`int` 是基本类型，`Integer` 是它对应的包装类（引用类型）。集合（`List`、`Map` 等）只能存引用类型，所以存整数时要用 `Integer`。Java 会自动在两者间转换（自动装箱/拆箱），1-07 集合那节会详细讲。

**Q：`System.out.println` 和 `System.out.print` 有什么区别？**  
A：`println` 打印后自动换行，`print` 不换行。还有 `System.out.printf` 支持格式化输出，类似 C 语言的 `printf`。

**Q：字符串拼接用 `+` 会有性能问题吗？**  
A：循环内大量拼接确实有问题，应该用 `StringBuilder`。日常少量拼接没关系。1-03 会讲。

**Q：`switch` 的 `default` 必须写吗？**  
A：不强制，但建议写，处理未预期的值，代码更健壮。
