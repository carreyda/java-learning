## 1. Java 是什么

Java 是一门**静态类型、面向对象**的编程语言，1995 年发布，至今仍是企业级后端开发的主流选择之一。

**Java 能做什么？**

- 后端 API 服务（Spring Boot，国内大厂标配）
- Android 移动应用开发
- 大数据处理（Hadoop、Spark 都基于 JVM）
- 桌面应用、嵌入式系统

**为什么学 Java？**

国内互联网公司（阿里、腾讯、字节、美团等）的后端服务大量使用 Java，招聘需求旺盛，生态成熟，面试体系完整。相比 Python/Node.js，Java 在大型系统的工程化、性能调优、多线程处理上有明显优势。

## 2. JDK 安装

JDK（Java Development Kit）是 Java 的开发工具包，包含编译器（`javac`）、运行时（`JRE`）和标准库。

### 2.1 选择版本

推荐安装 **JDK 17**，理由：

- LTS（长期支持）版本，稳定性有保障
- 国内主流企业已逐步升级到 17，面试也开始考查 17 新特性
- Spring Boot 3.x 要求最低 JDK 17

### 2.2 下载安装

**推荐使用 Adoptium（免费、无商业限制）：**

1. 访问 [https://adoptium.net](https://adoptium.net)
2. 选择 **Temurin 17 (LTS)**，下载对应系统安装包
3. 安装完成后验证：

```bash
java -version
# 输出类似：openjdk version "17.0.x" ...

javac -version
# 输出类似：javac 17.0.x
```

> **国内网络慢？** 可以从镜像站下载：[https://mirrors.tuna.tsinghua.edu.cn/Adoptium/](https://mirrors.tuna.tsinghua.edu.cn/Adoptium/)

### 2.3 配置环境变量（Windows）

安装程序通常会自动配置，如果 `java -version` 无法识别，手动配置：

1. 系统属性 → 高级 → 环境变量
2. 新建系统变量 `JAVA_HOME`，值为 JDK 安装路径（如 `C:\Program Files\Eclipse Adoptium\jdk-17.0.x.x-hotspot`）
3. 在 `Path` 中添加 `%JAVA_HOME%\bin`

macOS / Linux 通常安装后自动生效，无需手动配置。

## 3. IDEA 安装与配置

IntelliJ IDEA 是 Java 开发事实上的标准 IDE，远比 Eclipse/NetBeans 体验好。

### 3.1 下载

- 访问 [https://www.jetbrains.com/idea/download/](https://www.jetbrains.com/idea/download/)
- 选择 **Community 版**（免费，学习够用）
- Ultimate 版需付费，有学生认证或公司账号可使用

### 3.2 初次启动配置

1. 打开 IDEA，选择 **New Project**
2. 选择 **Java**，确认 JDK 路径已自动识别为刚安装的 JDK 17
3. 如未识别，点击 SDK 下拉框 → Add SDK → 选择 JDK 安装目录

### 3.3 推荐插件（可选）

| Rainbow Brackets               | 括号配色，嵌套层级更清晰 |
| Alibaba Java Coding Guidelines | 阿里巴巴 Java 规范检查   |

## 4. 第一个 Java 程序

### 4.1 创建项目

1. New Project → Java → 项目名填 `java-learning`，位置自选
2. 在 `src` 目录右键 → New → Java Class → 命名 `HelloWorld`

### 4.2 编写代码

```java
public class HelloWorld {
    public static void main(String[] args) {
        System.out.println("Hello, Java!");
        System.out.println("我的第一个 Java 程序");
    }
}
```

### 4.3 运行

点击 `main` 方法左侧的绿色三角 ▶，或右键 → Run 'HelloWorld.main()'

**控制台输出：**

```
Hello, Java!
我的第一个 Java 程序
```

### 4.4 逐行解析

```java
public class HelloWorld {          // 声明一个公共类，类名必须和文件名一致
    public static void main(String[] args) {  // 程序入口方法，固定写法
        System.out.println("Hello, Java!");   // 打印一行并换行
    }                              // main 方法结束
}                                  // 类结束
```

**和 JavaScript 对比：**

```javascript
// JavaScript：直接写，没有类的概念
console.log("Hello, JavaScript!");
```

```java
// Java：所有代码必须在类里面，有严格的结构要求
public class HelloWorld {
    public static void main(String[] args) {
        System.out.println("Hello, Java!");
    }
}
```

Java 比 JS 更"啰嗦"，但这种结构在大型项目中能提供更好的组织性和可维护性。

## 5. Java 程序是怎么运行的

这是 Java 最重要的一个特性——**"一次编写，到处运行"（Write Once, Run Anywhere）**。

```
源代码 (.java)
     ↓  javac 编译
字节码 (.class)
     ↓  JVM 解释/JIT 编译
机器码（在当前操作系统上运行）
```

**和 JavaScript 的区别：**

|          | Java                     | JavaScript             |
| -------- | ------------------------ | ---------------------- |
| 类型     | 编译型 + 解释型          | 解释型（JIT）          |
| 运行环境 | JVM                      | 浏览器 / Node.js       |
| 类型检查 | 编译时（写代码时就报错） | 运行时（跑起来才报错） |
| 性能     | 高，接近原生             | 中等                   |

**为什么 Java 能"到处运行"？**  
因为 `.class` 字节码不直接给操作系统运行，而是给 JVM 运行。不同操作系统装了各自版本的 JVM，字节码在所有平台上都一样，只有 JVM 不同。

## 6. 和 JavaScript 的对比感受

有 JS 基础来学 Java，有几个地方会比较不适应：

**必须声明类型**

```javascript
// JS：随便赋值
let name = "张三";
let age = 25;
```

```java
// Java：必须声明类型
String name = "张三";
int age = 25;
```

**所有代码必须在类里**

JS 可以直接写函数，Java 里函数（叫"方法"）必须属于某个类。

**分号不能省**

Java 每条语句必须以 `;` 结尾，不像 JS 可以省略。

**编译错误 vs 运行时错误**

JS 写了拼写错误的变量名，运行时才报错。Java 在你按下运行之前，IDEA 就已经用红线标出来了——这是静态类型的优势，项目越大越体现价值。

## 常见问题

**Q：`java -version` 显示版本不对，还是旧版本？**  
A：系统可能安装了多个 JDK 版本，检查 `PATH` 环境变量，确保新安装的 JDK 路径在前面。

**Q：IDEA 找不到 JDK？**  
A：File → Project Structure → SDK，手动添加 JDK 安装目录。

**Q：中文输出乱码？**  
A：IDEA 顶部菜单 → Help → Edit Custom VM Options，添加 `-Dfile.encoding=UTF-8`，重启 IDEA。

**Q：`public class HelloWorld` 里的 `public static void main` 是什么意思？**  
A：现在先把它当固定写法记住，`1-04` 面向对象那节会详细解释每个关键字的含义。
